# 学习与探索的地基

> **一句话**：3 岁前最值得保护的，不是提前学会多少，而是孩子愿意观察、互动、尝试和回来继续探索。

## 先从一个常见场景说起

宝宝把勺子丢到地上，大人捡回来；宝宝又丢，大人又捡。到了两岁，孩子对着窗外的车问个不停，却不肯按大人的要求坐下来“学十分钟”。

这些行为看起来零散，其实都和学习有关。孩子在确认因果，分享注意，练习语言，也在观察大人是否会回应自己。这个阶段不需要把游戏改造成练习册。

## 3 岁前正在发展什么

| 大致阶段 | 可以关注的变化 | 成人可以提供的条件 |
|---|---|---|
| 0–6 个月 | 对声音、脸和熟悉的回应有反应；短暂看向有趣的事物 | 及时回应哭声和表情，面对面说话，给安全的自由活动空间 |
| 6–12 个月 | 重复拍、抓、扔来观察结果；开始跟随目光或手指 | 跟着孩子看同一件东西，用简单词命名，允许在安全范围内重复探索 |
| 12–24 个月 | 指给成人看、模仿、假装使用物品；出现“我自己来” | 给有限选择，提供简单材料和假装游戏，等待孩子完成尝试 |
| 24–36 个月 | 用更多语言提问和表达，能把经验带进游戏和故事 | 认真听问题，和孩子一起查找答案，把生活任务拆成一小步一小步 |

这不是月龄考核表。孩子的语言、动作、社交和注意发展不一定同步，单次没有做出来也不能说明能力有问题。更有用的是看一段时间里，孩子是否持续获得新经验，以及成人支持后能否更容易参与。

## 六种日常支持

### 1. 先回应，再引导

孩子看向你、发出声音、指一个物品或把东西递过来时，先回应这个信号，再决定要不要加一点内容。你可以说：“你看到车了。红色的车开过去了。”回应不需要很长，重点是让孩子感到这次互动有来有回。

如果孩子已经累了、饿了或被声音吓到，先处理身体和情绪，不要在这时安排“认知训练”。休息和被安抚，也是继续学习的条件。

### 2. 跟随共同注意

不要急着把孩子的目光拉到你准备好的卡片上。先看他在看什么，再加入进去：

1. 站到孩子能看到的位置；
2. 看同一件东西，用一两个词描述；
3. 等孩子看你或再指向物品；
4. 轮到你时，再补充一个动作或问题。

共同注意不是要求孩子“看我”。它更像是两个人知道自己正在看同一件事。

### 3. 给安全的因果体验

把按钮、纸盒、勺子、水杯和积木变成可探索的材料，前提是没有吞咽、烫伤、夹伤和跌落风险。孩子反复打开、关闭、敲击或丢东西时，可以说：“你松手，球就滚走了。”不必每次都替他完成，也不必为了让游戏更快而马上给答案。

详细的动作和材料边界可以看[因果关系推理](cause-effect-01.md)和[符号思维萌芽](symbolic-thinking-01.md)。

### 4. 把生活说出来

换尿布、洗手、穿衣、买菜和收玩具都可以成为语言互动。说出正在发生的事，也给孩子留一小段回应时间：“我们先把袜子放进篮子，再去洗手。”孩子没有回应时，继续做事即可，不需要把每一次互动都变成问答。

家里使用一种或多种语言都可以。稳定、自然、愿意交流的语言输入比机械重复词卡更重要。语言发展的具体阶段可参考[母语发展（0–3 岁）](../../../../../interests/language/母语发展/0-3岁.md)。

### 5. 保留自由游戏和假装游戏

给孩子几件简单、开放的材料：纸盒、布、积木、勺子、玩偶和绘本。孩子把积木当电话、给玩偶喂饭或用布搭小屋时，先跟着他的设定走，再问：“小熊现在要去哪里？”成人不必纠正“正确玩法”。

假装游戏不需要昂贵道具，也不要求每天完成多少分钟。它让孩子练习把一个物品当成另一个东西使用，也为后来的叙事、计划和观点理解提供经验。

### 6. 让书保持轻松

孩子啃书、拍书、只看图片或反复读同一本，都可以是早期阅读的一部分。每天选一个孩子状态不错的时段，读一两页也可以。顺着孩子指的图片说两句，孩子想翻页就翻，不必每页提问或检查记住了多少。

更多实操见[早期阅读探索](early-reading-01.md)。屏幕不能替代面对面互动；视频通话等需要成人陪伴的社交使用，也不等于把录播视频一直放在旁边。边界可参考[婴幼儿屏幕管理](screen-time-01.md)。

## 什么不需要急着做

- 不需要把字卡、闪卡或早教视频当作每天必做任务；
- 不需要要求孩子按成人安排持续坐着；
- 不需要把“看起来聪明”解释成读得早、数得快或背得多；
- 不需要把孩子暂时不感兴趣的活动加码成更长、更难的训练；
- 不需要为了追赶别人的进度，牺牲睡眠、自由活动和亲子关系。

如果孩子愿意重复一个简单动作，成人可能会觉得无聊，但对孩子来说这正是他在收集信息。安全范围内可以让他多试几次。

## 需要关注的信号

以下不是自我诊断标准。若情况持续、明显影响日常互动，或照料者直觉觉得不对，可以在儿童保健或儿科就诊时提出：

- 已经获得的语言、动作或社交技能出现倒退；
- 长时间很少回应声音、面孔或他人的互动，也很少用眼神、手势或声音分享兴趣；
- 对环境中几乎所有安全物品都不愿意观察、触碰或尝试，且支持和休息后仍没有变化；
- 听力、视力、进食、睡眠或情绪问题已经影响孩子参与游戏和交流。

专业人员会结合听力、视力、发育、健康和家庭环境来判断，不会只凭一个行为下结论。

## 今天就能做的一件事

找一个孩子已经在看的东西，坐到旁边，用一句话描述它，然后安静等几秒，看孩子是否继续看、指或发出声音。今天不加问题，也不测试答案。
