# 0-3 岁发展观察框架

## 这不是一张打分表

0–3 岁的孩子发展速度和表现方式差异很大。同一个孩子在家里、托育环境和陌生场所也可能表现不同；睡眠、饥饿、疾病、早产校正年龄、语言环境和照料者互动都会影响一次观察。

这份框架的用途是帮助你回答三个问题：

1. 我现在看到的具体行为是什么？
2. 我可以提供什么安全、低压力的机会或环境调整？
3. 什么情况下应该停止自行观察，带着记录去咨询专业人员？

CDC 的里程碑清单适合帮助家庭和专业人员沟通，也提醒家长在错过里程碑、出现技能倒退或有其他担忧时尽早行动；它不是标准化诊断工具，也不能用全量项目的得分替代筛查和评估。[CDC 里程碑说明](https://www.cdc.gov/act-early/milestones/key-points.html)

## 建议的观察方法

不需要按月做全套评估。孩子出现一个新问题，或照料者持续担心时，可以用下面的短记录：

| 记录项 | 示例 |
| --- | --- |
| 日期和年龄 | 2026 年 8 月，14 个月；如早产，注明校正年龄和医生建议 |
| 真实场景 | 吃饭、洗澡、地面游戏、出门、照料者离开后 |
| 看到的行为 | 转头、伸手、寻找、咳嗽、拒绝、指物、回到成人身边 |
| 孩子状态 | 清醒、困倦、饥饿、生病、陌生环境、刚换照料者 |
| 成人做了什么 | 降低声音、给选择、换姿势、等待、停止、提供帮助 |
| 后来怎样 | 继续参与、恢复、仍然痛苦、出现新问题或没有变化 |

观察重点是变化和情境，不是“完成/未完成”或“比别人早/晚”。如果担心，短视频和这类记录通常比一张总分表更适合带给专业人员。

## 一、按年龄阶段进入

### 0–6 个月：安全、回应和身体探索

可以观察：孩子是否在清醒时对声音、脸和照料者的回应逐渐增加；是否有安全的地面活动和伸手、转头、抓握机会；喂养时是否舒适、呼吸和吞咽是否协调。

家庭可以做：回应孩子的声音和表情，提供有人看护的地面活动，按孩子线索喂养，保护安全睡眠，不用屏幕或固定训练替代互动。

深入内容：[安全依恋](认知与心理/attachment-01.md) · [粗大动作](身体能力/gross-motor-01.md) · [精细动作](身体能力/fine-motor-01.md) · [口部运动](身体能力/oral-motor-01.md)

### 6–12 个月：移动、寻找和来回互动

可以观察：孩子是否逐渐伸手、转身、移动、寻找被遮挡物品、重复动作—结果游戏，是否开始用声音、手势和眼神参与来回互动；新质地进食时是否安全。

家庭可以做：提供安全地面空间和可抓握材料，玩短暂的躲猫猫和藏玩具，回应孩子指向和发声，遵循准备信号进行辅食质地过渡。

深入内容：[客体持续](认知与心理/object-permanence-01.md) · [因果探索](认知与心理/cause-effect-01.md) · [联合注意](认知与心理/joint-attention-01.md) · [感觉体验](身体能力/sensory-integration-01.md)

### 12–18 个月：自主行动、共同注意和日常参与

可以观察：孩子是否通过手势、声音或词语表达需要，是否在安全关系中探索和回来确认，是否出现选择、拒绝、假装、放入容器和自主进食等参与方式。

家庭可以做：给有限且都安全的选择，描述孩子的行动和情绪，提供容器、翻页、收拾和安全进食机会，不用强迫分享或镜子测试判断发展。

深入内容：[自我与自主意识](认知与心理/self-awareness-01.md) · [自主性](认知与心理/autonomy-01.md) · [精细动作](身体能力/fine-motor-01.md) · [早期阅读](认知与心理/early-reading-01.md)

### 18–24 个月：语言、假装和关系中的协商

可以观察：孩子是否用更多方式表达想法，是否能参与简单共同活动、假装游戏、轮流和日常任务；情绪激烈时是否能在成人支持下逐渐恢复。

家庭可以做：把语言放进真实活动，给孩子参与小任务的时间，使用简单边界和替代方案，允许重复游戏，不把“说了多少词”单独当作整体发展结论。

深入内容：[符号思维](认知与心理/symbolic-thinking-01.md) · [共情](认知与心理/empathy-01.md) · [语言兴趣路径](../../../../interests/language/母语发展/0-3岁.md)

### 24–36 个月：表达、自主和更复杂的游戏

可以观察：孩子是否能参与更长的对话和假装游戏，是否开始描述经历、表达偏好、理解简单轮流规则，动作和进食工具是否继续变化。

家庭可以做：和孩子共同讲述生活、让他参与收拾和选择、提供安全的跑跳和搭建空间，留意语言、听力、动作、进食或社交沟通方面的持续担忧。

深入内容：[早期阅读](认知与心理/early-reading-01.md) · [自我与自主意识](认知与心理/self-awareness-01.md) · [粗大动作](身体能力/gross-motor-01.md)

## 二、按能力域选择观察问题

| 能力域 | 更适合记录什么 | 不要用来做什么 |
| --- | --- | --- |
| 关系与回应 | 孩子如何寻求安慰、分享兴趣、在支持下恢复 | 不用一次哭不哭判断依恋质量 |
| 语言与共同注意 | 看、指、发声、模仿、理解和表达出现在哪些情境 | 不用单一词数诊断语言能力 |
| 动作 | 新动作、左右使用、舒适度、环境是否提供机会 | 不用爬行或走路的单一日期给孩子排名 |
| 手部与进食 | 抓握、放下、工具使用、坐姿、质地和吞咽安全 | 不用食物或口部游戏训练语言发音 |
| 认知探索 | 寻找、重复、改变方法、假装和生活连接 | 不用躲猫猫或按钮游戏做智力测试 |
| 感觉与适应 | 触发因素、孩子状态、环境调整和日常影响 | 不凭一种偏好诊断“感统失调” |
| 自我与自主 | 选择、拒绝、展示、所有权、情绪和参与 | 不把“我的”或不分享等同于自私 |

## 三、把观察变成四周行动

可以使用一个很小的循环：

1. **选择一个问题**：例如“洗头时总是哭”“还没有主动指物”“吃新质地会咳嗽”。
2. **记录真实情境**：不额外制造测试，记录孩子状态、触发因素和成人回应。
3. **做一个低风险调整**：改变姿势、环境、材料、语言或等待时间，只改一个变量。
4. **一周后复盘**：是更容易参与了，还是没有变化、变得更糟，或出现新的红旗？

如果没有改善，不代表家长做错了，也不意味着要不断增加训练。可能需要更换策略、减少压力，或寻求专业评估。

## 四、何时咨询专业人员

建议尽早带着具体记录咨询儿科、儿童保健、听力、发育行为、吞咽或言语语言专业人员的情况包括：

- 已经会做的动作、沟通、进食或互动能力明显倒退；
- 持续明显单侧无力、动作僵硬或松软、疼痛，或移动和进食明显不舒服；
- 进食反复咳嗽、呛咳、湿嗓、呼吸费力、含食，或营养和水分受到影响；
- 在多个熟悉场景中持续很少回应声音、名字、手势或互动邀请；
- 感觉反应、情绪或行为持续影响睡眠、进食、洗澡、穿衣、安全或家庭关系；
- 照料者直觉持续担心，或不知道如何安全支持孩子。

出现呼吸困难、发青、意识改变、严重受伤、疑似窒息或严重过敏反应时，不继续做家庭观察，立即呼叫当地急救服务。

## 五、给专业人员的观察摘要模板

可以复制下面的结构，不需要先给孩子下结论：

```text
孩子年龄/校正年龄：
我最担心的一个问题：
这个问题从什么时候开始：
出现在哪些具体场景：
孩子当时的状态（清醒、疲劳、饥饿、生病、陌生环境等）：
我观察到的行为（尽量写动作，不写“落后/不正常”）：
我尝试过的调整：
调整后的变化：
是否有倒退、疼痛、呼吸、进食或安全问题：
我希望专业人员帮助判断什么：
```
