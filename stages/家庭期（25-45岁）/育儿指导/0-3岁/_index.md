# 宝宝照料与成长：需要时查

想从头理解养育过程，进入[准备出生到三岁](../../../../paths/parenting/new-parent/_index.md)。那份目录安排连续阅读；这里帮你找眼前的操作或发展问题。

有呼吸、反应、体温、出血或即时安全担忧，先看[安全与求助](../quick-start.md#safety)。已经会做的动作或交流明显倒退，或你持续觉得不对，也可以直接联系儿科或儿童保健人员。
