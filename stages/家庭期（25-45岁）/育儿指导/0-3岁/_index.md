# 婴幼儿期（0-3岁）

## 阶段概述

0–3 岁是身体、关系、感知和行动快速变化的时期。孩子通过被照料、与人互动和安全探索，逐渐形成对环境的熟悉感，也逐步发展感知、动作、沟通和自我调节能力。

对孩子来说是如此，对父母来说也一样。成为父母会带来新的照料任务和生活安排，所以本阶段同时放入孩子的发展主线和**父母支持主线**。

> **新手爸妈？** 如果你是第一次当爸妈，可以先看[新手爸妈教程：产前两个月到宝宝六个月](../quick-start.md)，按时间线学习，也可直接查眼下要用的护理步骤。

## 阶段关注点

- 用稳定、回应式的照料建立安全感，让孩子在需要帮助时得到及时回应。
- 在说话、指物、共读和游戏中创造共同注意，把语言和关系放进日常互动。
- 提供安全、可自由探索的环境，跟随孩子的动作、感官和兴趣。
- 结合一段时间内的可观察变化调整支持；照料者疲惫或担忧时也应先获得支持。睡眠、喂养和安全照护优先于额外训练，不用训练强度衡量养育质量。

## 如何使用本阶段

年龄是这里的第一入口。先按孩子当前月龄定位阶段，再根据正在处理的问题或想支持的能力选择文章，不需要一次读完整个目录。

可以用一个小循环阅读：

```text
理解一个主题 → 做一个小行动 → 观察一段时间 → 复盘并决定是否调整
```

- 遇到哭闹、喂养、睡眠等当下问题，先看[日常护理指南](日常护理/_index.md)和安全提示。
- 想支持发展能力，从“能力培养主线”进入，再看文章中的行动与观察信号。
- 照料者已经疲惫、低落或无法承担时，先进入[父母自身支持](../父母自身/_index.md)，不要把所有问题都转化成孩子的训练任务。

## 发展评估

**[→ 发展路线图与评估框架](development-assessment.md)**：提供按年龄浏览的观察线索、能力主线和记录模板。它用于帮助你提出更具体的问题、看见一段时间内的变化，不是需要定期打分或完成的测试；持续担忧、明显倒退或安全问题应咨询合格专业人士。

## 培养过程

从回应哭声、轮流发声、共同看书和安全的自由探索开始，观察孩子如何看向你、跟随关注、尝试动作或邀请你参与。再按当前情境进入具体文章，不需要为了“补齐能力链”安排训练。孩子的发展速度有差异；如果技能明显倒退或担忧持续，再寻求专业评估。

### 月龄观察地图

> 以下内容用于帮助你找到观察角度，不是达标表。孩子可能在同一阶段表现出不同的组合，也可能因睡眠、健康、早产经历、环境和兴趣而出现波动。

### 孕晚期至出生：准备照料环境

| 关注方向 | 可以先做什么 |
|------|---------|
| 产前准备 | 了解基本护理、支持来源、喂养计划和产后分工 |
| 家庭环境 | 把睡眠、换尿布、喂养和求助信息放到容易找到的位置 |

### 0–4 个月：感知、关系与身体舒适

| 关注方向 | 可以观察的变化 |
|------|---------|
| 关系与沟通 | 对人声、脸、触摸和熟悉的回应有不同反应；用哭声、表情或声音表达状态 |
| 日常护理 | 喂养、湿尿布、睡眠、皮肤和体温；优先建立安全稳定的照料流程 |
| 身体活动 | 清醒且有人看护时有短暂的地面活动和俯卧机会，按孩子状态调整 |
| 共同经验 | 通过唱歌、说话、看脸、看图片和安全触摸形成来回互动 |

### 4–8 个月：重复探索与沟通变化

| 关注方向 | 可以观察的变化 |
|------|---------|
| 动作与探索 | 抓、拍、摇、推或放下物品，重复观察结果；坐、翻身和移动方式可能不同 |
| 沟通 | 咿呀、表情、目光、伸手、递物或其他手势逐渐增多 |
| 共同关注 | 可能跟随成人的目光或手势，也可能先从自己正在看的东西发起互动 |
| 物品寻找 | 逐渐留意被遮挡或移开的熟悉物品，不把一次寻找当成测试 |

### 8–12 个月：手势、移动与生活经验

| 关注方向 | 可以观察的变化 |
|------|---------|
| 身体移动 | 扶站、扶家具移动、爬行或其他移动方式可能交错出现；独立行走不必在这一段完成 |
| 早期沟通 | 理解熟悉词或动作，可能用挥手、指向、递物、发声或其他方式表达 |
| 精细动作 | 抓取、传递、捏取和把物品放入容器等尝试逐渐丰富 |
| 共读与游戏 | 啃书、拍书、翻页、看图片和模仿声音都可以是互动入口 |

### 12–18 个月：行动、模仿和早期假装

| 关注方向 | 可以观察的变化 |
|------|---------|
| 行走与参与 | 有些孩子开始独立走几步或更多，有些仍在扶走和练习平衡；看他是否愿意在安全环境中移动和参与 |
| 沟通 | 可能出现更多有意图的声音、词语、手势或简单理解，速度有差异 |
| 游戏 | 模仿喝水、打电话、做饭等熟悉动作；是否使用替代物不作为家庭测试 |
| 关系与自我 | 可能表达偏好、靠近熟悉照料者，或用目光、声音和动作邀请成人关注 |

### 18–24 个月：自主、互动和生活游戏

| 关注方向 | 可以观察的变化 |
|------|---------|
| 自主行动 | 可能说“我自己来”、拒绝帮助、参与穿衣收拾或在两个选项中做决定 |
| 情绪与关系 | 可能注意到他人的状态，在成人示范下参与等待、帮助或修复；不要求每次都安慰或分享 |
| 假装游戏 | 可能给娃娃喂饭、用容器做饭，或重复一小段熟悉情节 |
| 身体与工具 | 继续练习走、跑、蹲起、拿勺和涂画；不把某一项动作当作单独诊断线索 |

### 24–36 个月：表达、合作与扩展游戏

| 关注方向 | 可以观察的变化 |
|------|---------|
| 自主与边界 | 在熟悉流程中参与更多步骤，也可能因疲劳或转场重新需要成人帮助 |
| 语言与故事 | 用更长的短句、问题、生活片段或假装对话表达；清晰度和叙述能力有差异 |
| 游戏与材料 | 可能把纸盒、积木、布和生活物品换作不同用途，或连接两个以上动作 |
| 精细动作与阅读 | 继续练习翻页、涂画、搭建、使用餐具和看图讲述，不把剪纸、描线或预测情节设为达标项 |

## 参考框架如何使用

### 公共卫生与发展观察参考

- [CDC 发展里程碑](https://www.cdc.gov/act-early/milestones/index.html)：用于记录和沟通，不是家庭诊断工具或训练清单。
- [WHO 婴幼儿身体活动、静坐和睡眠指南](https://www.who.int/publications/i/item/9789241550536)：用于安排活动、睡眠和静坐时间的公共卫生参考，不是个体能力标准。

### 理论视角

依恋、感知运动、早期自主和自我意识等理论，可以帮助理解孩子的行为和关系经验；它们不是用来给孩子贴标签，也不能替代筛查、诊断和治疗。页面中的具体安全建议优先采用儿科、公共卫生、听力和发育专业机构的现行指南。

### 家庭互动与内容组织资源

Raising Children Network、ZERO TO THREE、UNICEF 等资源可帮助我们组织年龄入口、游戏和家庭行动。它们用于启发结构和表达；涉及医疗、安全和发展风险时，仍以权威专业来源和当地服务为准。
