# 父母与照料者支持

照料者的休息、身体、情绪和关系，与孩子的成长同时发生。这里提供支持，不把父母文章算作孩子年龄主线的进度；从孩子主线查过来时，优先用页面的“返回主线原章节”继续原来的阅读。

## 有立即危险，先求助

有伤害自己或孩子的想法、幻觉、妄想、严重混乱或无法保证安全时，让可信任成人接手孩子并陪同当事人，联系当地急救、危机支持或急诊，不先完成阅读。身体急症也不能归为“只是情绪不好”。危机处理与产妇身体警示参考 [NIMH 围产期抑郁](https://www.nimh.nih.gov/health/publications/perinatal-depression)和[CDC 产妇紧急警示信号](https://www.cdc.gov/hearher/maternal-warning-signs/index.html)。

## 没有立即危险，从当前处境开始

- **还在孕期**：从下面短路线第一篇读起，把支持与分工提前说清。
- **宝宝已经出生**：可以从第二篇开始；今晚困到无法安全照料时，直接查第三篇，不用补产前课程。
- **情绪或生活功能持续变差**：直接查第四篇并联系专业人员，不等满某个天数。
- **孩子已经更大**：在下方按当前问题选读，查完返回[孩子当前年龄路线](../_index.md)。

## 新生儿家庭的四篇短路线

1. [产前准备与迎接新生儿](产前准备/prenatal-preparation-01.md)：准备联系人、物品与真实分工。
2. [新手父母心理调适](产后调适/parental-wellbeing-01.md)：把恢复、情绪变化和支持放回家庭生活。
3. [睡眠剥夺应对](产后调适/sleep-deprivation-01.md)：安排一段连续休息和安全交接。
4. [产后抑郁识别与应对](产后调适/postpartum-depression-01.md)：了解持续困扰、危机和求助；孕期及产后出现相关症状都可阅读，月份不作求助截止点。

父母支持与[从准备出生到三岁的主线](../../../../paths/parenting/new-parent/_index.md)并行；不需要为了继续孩子章节读完这里全部内容。
