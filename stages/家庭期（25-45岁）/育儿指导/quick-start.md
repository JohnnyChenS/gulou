# 新手爸妈教程：产前两个月到宝宝六个月

你不需要先懂“开指”“恶露”“含接”才配读这篇教程。下面会从准备去医院开始，把妈妈、宝宝和照料者分别需要做的事讲清楚。第一次不会抱、分不清哭声、需要护士再教一次，都很常见。

**这篇的目标是让你知道下一步怎么做，而不是给家里增加一张必须全部完成的考核表。** 还没出生时，可以按顺序读；已经回家时，直接找当前时间段或具体操作。

适用范围：以中国大陆普通家庭、医院分娩、健康足月婴儿为主要场景，覆盖预产期前约两个月至宝宝满六个月。预产期是估计日期，不是一定会出生的日子；早产、高危妊娠、低出生体重、住院治疗或特殊喂养需求，以主管团队的个体方案为准。“伴侣”也可以替换为家人或其他可信任的照料者，没有伴侣不妨碍建立支持安排。

**资料核对日期：2026-09-17。本文为循证育儿科普修订稿，尚待产科、儿科及相关专业人员复核，不等同于已完成专家审定，也不替代诊疗。** 医疗安排、筛查、接种和用药以所在地机构及本人的医嘱为准。相关依据紧邻正文，完整目录见[孕产与婴儿早期照护资料](../../../references/early-parenthood-care.md)。

## 先处理安全问题

如果现在正在发生下列情况，先求助，不要为了看完教程而等候。以下不是所有危险情况的完整清单；你明显感觉“不对劲”，也可以直接联系医疗团队。

### 立即呼叫急救或去急诊

中国大陆医疗急救拨 **120**；其他地区使用当地号码。已经在医院里，立即按呼叫铃、叫护士。打电话先说位置、谁出了什么问题、是否有意识和正常呼吸。

| 对象 | 现在看到什么 | 立即做什么 |
|---|---|---|
| 妈妈 | 大量阴道出血、晕厥、胸痛、呼吸困难、抽搐、意识混乱 | 呼叫急救；不要自己开车，也不要独自抱宝宝走动 |
| 孕妇 | 强烈想用力、感觉宝宝马上要出来，无法安全自行到院 | 呼叫急救，听调度指引，不自行拉拽宝宝或脐带 |
| 宝宝 | 呼吸费力、胸口或肋骨下明显凹陷、嘴唇或舌头发蓝灰；没有反应、难以唤醒、抽搐 | 呼叫急救；若没有正常呼吸，按调度指导或已受训的婴儿心肺复苏方法处理，不能只放下等待 |
| 宝宝 | 绿色呕吐，尤其伴腹胀、精神差；明显带血呕吐 | 立即急诊评估，状态差或无法安全运送时呼叫急救，不按普通吐奶继续观察 |
| 任何照料者 | 有伤害自己或宝宝的冲动、计划，出现幻觉、妄想、严重混乱，无法保证安全 | 让可信任成人立即接手宝宝并陪住当事人，联系急救，不让其独处 |

宝宝呛咳时，如果还能有力咳嗽和呼吸，先停止喂奶并持续在旁观察；**不能出声、不能有效咳嗽或呼吸时是急症**。立即呼救，按调度或受训方法开始处理，不只等待救护车。不要倒提、摇晃或盲目把手指伸进嘴里掏；一岁以内不用腹部冲击法。产前应参加有模型练习的婴儿急救课，文字阅读不能代替操作训练。[NHS：婴儿窒息急救](https://www.nhs.uk/baby/first-aid-and-safety/first-aid/how-to-stop-a-child-from-choking/)

急症辨识参考：[NHS：新生儿危险信号](https://www.asph.nhs.uk/caring-for-your-newborn)、[NHS：绿色呕吐须急诊评估](https://www.uhsussex.nhs.uk/resources/bilous-vomiting-by-your-baby/)。

### 立即联系产科，不等下次产检或“满月复查”

- 孕期胎动比平时明显减少或停止；疑似破水；阴道出血超过少量血丝。不要靠喝甜水、胎心仪或睡一觉排除危险。
- 孕期或产后出现持续或加重的剧烈头痛、视物异常、严重腹痛、体温 **38°C 或以上**、单侧腿部红肿疼痛。
- 产后出血突然增多，**一小时浸透一片或更多卫生巾**，或排出比鸡蛋大的血块；有头晕、心慌时按急救处理。不要为了“凑够一小时”才求助。
- 分泌物恶臭、伤口红肿流脓或裂开。严重疼痛、寒战、全身状态差时急诊处理。

孕产相关严重并发症可能发生在分娩后一年内。就医时主动说“我怀孕了／我在某日生过孩子”。以上警示依据 [CDC 产妇紧急警示信号](https://www.cdc.gov/hearher/maternal-warning-signs/index.html)。

### 宝宝需要立即联系儿科或当天就诊

- **3 个月及以下，直肠温度达到 38°C 或以上，即使精神看起来还可以，也立即联系儿科并按安排接受评估。** 家里量到其他部位 38°C、体温偏低伴精神差，或怀疑发热但量不准，也不要等复测才联系。先不要自行喂退热药掩盖病情。[AAP：婴儿发热](https://www.healthychildren.org/English/health-issues/conditions/fever/Pages/Fever-and-Your-Baby.aspx)
- 明显吃不进、吸吮无力、尿量明显减少、反复喷射呕吐、大便带血或灰白。很难叫醒、呼吸异常时升级为急救。
- **出生头 24 小时就发黄**，或黄疸合并嗜睡、拒奶、没有湿尿布，立即急诊评估。后来才发黄也要让医护判断，不能只凭照片或皮肤颜色说“正常”。[NHS：新生儿黄疸](https://www.nhs.uk/conditions/jaundice-in-babies/)
- 脐周红肿扩大、有脓或臭味，特别是伴发热、吃得少。

3–6 个月宝宝出现发热，也应及时联系儿科说明体温和状态；年龄变大不意味着发热一定能在家等。任何年龄都先看呼吸、精神和摄入情况。

## 预产期前 8–5 周：先把“人、医院、家”准备好

以预产期约 40 周估算，这大致是孕 32–35 周。已有早产风险或医生要求提前准备时，不等这个时间点。

### 1. 建立一张能够直接拨号的联系表

在手机和纸上各留一份，伴侣也要能找到：

| 联系对象 | 要提前问清什么 |
|---|---|
| 分娩医院产科 | 白天和夜间分别去哪个入口；疑似破水、出血、胎动减少联系哪里；哪些材料要带 |
| 日常产检团队 | 接下来的检查时间；本人有哪些特殊风险；什么情况必须提前来；现用药是否继续 |
| 儿科／新生儿科、社区卫生服务中心 | 出院后谁随访、怎么预约；夜间宝宝不舒服去哪里 |
| 主要照料者和替补 | 谁陪产，谁送饭，谁处理家务；主要照料者生病或撑不住时谁能接手 |

产检时可以直接说：“我们完全没有带孩子经验，请把入院条件和回家后的随访写给我们。”不要自行停降压药、精神科药物或其他长期用药；让产科与原开药医生共同安排。

### 2. 妈妈自己的日常照护继续进行

待产准备不能挤掉吃饭、休息和产检。继续多样饮食，不因“宝宝最后长得快”强迫吃双份；已经有血糖、血压或贫血方案时照方案执行。按身体状态和产科许可保持轻柔活动，不为了好生而突然爬很多楼梯或做高强度训练。疲倦时休息，用品采购可以交给别人。[NHS：孕 32 周生活指导](https://www.nhs.uk/best-start-in-life/pregnancy/week-by-week-guide-to-pregnancy/3rd-trimester/week-32/)

每天留意自己熟悉的胎动模式，明显变少就联系产科，不把“快生了地方小，所以少动”当成解释。有持续失眠、恐惧，或既往抑郁、双相障碍等情况，提前告知团队并安排产后支持。

### 3. 讨论一次分娩偏好，而不是承诺一种分娩结果

妈妈可以表达想由谁陪同、需要怎样的解释、是否希望了解分娩镇痛、稳定后是否愿意肌肤接触和尝试母乳喂养。问医院哪些服务可提供，什么情况下需要调整。

“无痛分娩”通常指由麻醉团队评估的椎管内镇痛，它用于减轻产痛，并非承诺全程没有感觉。提前了解适应证、风险和可用时间。临时想用镇痛或需要剖宫产，并不代表意志不够。[NHS：分娩镇痛选择](https://www.nhs.uk/pregnancy/labour-and-birth/pain-relief-in-labour/)

### 4. 把照料分工写成完整任务

不要只写“爸爸帮忙”。下面是一份可以改写的家庭安排：

| 任务 | 负责人需要做到哪里 |
|---|---|
| 妈妈吃饭和喝水 | 采购、做好、端到手边、收拾；不等妈妈提醒 |
| 尿布和安抚 | 准备用品、完成操作、观察异常、把宝宝安全放回床 |
| 瓶喂相关工作（如需要） | 按方案备奶、喂奶、处理剩奶、清洗消毒，不把收尾留给另一人 |
| 医疗安排 | 预约、出行、保管报告、查询结果、安排复诊 |
| 夜间交班 | 约定谁醒着负责、何时叫另一人、何时请替补 |
| 访客和长辈沟通 | 由一人统一联系，保护妈妈休息和隐私 |

如果只有一个成人照料，优先提前安排送餐、家务支持和可到场替补；不要把“一个人扛完”作为默认方案。更多讨论见[产前准备与迎接新生儿](父母自身/产前准备/prenatal-preparation-01.md)。

### 5. 家里先准备三个位置

- **睡眠位置**：父母房间里的独立婴儿床或摇篮，床垫平坦坚实、贴合床框，只铺合适的床单。床边没有窗帘绳、电线、烟和暖风直吹。细则见[安全睡眠](#sleep)。
- **换尿布位置**：清洁的地面垫最容易防跌落；尿布、清洁用品、垃圾桶伸手可及。若用高处护理台，成人始终一手护住宝宝。
- **喂养位置**：成人坐得稳、背和手臂有支撑，旁边能放水和记录卡；附近没有热汤、热水壶。夜间能开小灯看清宝宝脸色。

### 6. 用品按“现在要用”采购

| 类别 | 最低实用配置 | 先别因为焦虑购买 |
|---|---|---|
| 宝宝衣物与清洁 | 易穿脱衣服数套、少量新生儿尿布、柔软毛巾、清水清洁用品、浴盆 | 大量同尺码囤货、香粉、香味很重的洗护套装 |
| 睡眠 | 合规床具、配套床垫床单、合身非加重睡袋（按需要） | 定型枕、床围、斜坡垫、睡眠定位器、加重睡袋 |
| 健康记录 | 数字体温计、出院资料夹、可记录时间的手机或纸笔 | 把家用血氧／心率监测器当作预防猝死的保障 |
| 喂养 | 按计划准备；若瓶喂，备易清洁奶瓶、适龄奶嘴、专用刷和消毒设备 | 为“以后可能有用”囤大量特殊奶粉和催乳产品 |
| 妈妈 | 大号卫生巾、舒适内裤和宽松衣物、日常洗漱用品、方便吃的食物 | 未经评估的紧束腹带、私处清洗液和“排毒”产品 |
| 出行 | 自驾／乘车需要时，提前安装适合婴儿的后向式安全座椅 | 认为成人抱着坐车比安全座椅稳 |

两位照料者各用玩偶练习抱起、放下和换尿布，再报名医院的新生儿护理或急救实操课。此时不要求动作熟练，但要知道哪些动作必须有人当面教。

## 预产期前 4–1 周：把准备变成随时能出门的状态

### 待产包分三袋，陪产者也知道位置

按医院清单调整，约预产期前 3 周准备就绪；有风险时更早。不是所有医院都需要自带相同物品。[NHS：待产包清单](https://www.nhs.uk/start-for-life/pregnancy/preparing-for-labour-and-birth/hospital-bag-checklist/)

- **证件资料袋**：身份证件、医保相关材料、产检记录和检查结果、药物与过敏清单、医院要求的文件、手机和充电器。
- **妈妈袋**：卫生巾、内裤、前开或宽松衣物、防滑拖鞋、洗漱用品、眼镜、水杯；吃喝遵守病区及麻醉要求。
- **宝宝袋**：医院要求的尿布和衣物、出院衣物；瓶喂用品按医院允许方式准备。安全座椅装在车上，不等出院才研究。

实际走一遍到院路线，确认夜间入口、停车和替代交通。谁拿包、谁通知家人、谁照看家里其他孩子或宠物，也提前分好。

### 先认识三个词

| 词语 | 可能是什么感觉 | 该怎么做 |
|---|---|---|
| 宫缩 | 子宫收紧，肚子一阵阵变硬，可能伴腰腹痛 | 记录开始时间、持续多久、两次开始之间的间隔；是否需要到院由产科结合孕周和个人风险判断 |
| 见红 | 少量带血丝的黏液 | 与月经量出血不同；可能离分娩还有时间。不确定出血量、伴其他异常时联系产科 |
| 破水 | 阴道突然流出液体，或持续滴漏，可能控制不住 | 即使不痛也立即联系产科；用卫生巾承接并记下时间、颜色和气味，不用棉条、不自行内检或同房 |

**不要死等“宫缩每五分钟一次持续一小时”。** 这是有些机构给特定孕妇的参考，不适合替代你的入院方案。未满 37 周疑似发动、胎动减少、明显出血、羊水绿褐色或恶臭，都应立即联系产科并按指示到院。破水后不能自行决定“在家等一天”。[NHS：临产信号](https://www.nhs.uk/pregnancy/labour-and-birth/signs-that-labour-has-begun/)

如果产科判断可以暂时在家，问清下一次联系时间、什么变化立即回来，以及是否可以进食和活动。不要自行用药、偏方或刺激乳头催产。

<a id="birth-day"></a>

## 生产当天：妈妈表达感受，伴侣负责支持和信息

### 出发前到入院

1. 有急症先呼叫急救，拿齐东西不能排在求救之前。普通到院按产科安排出发，妈妈不要自己驾车。
2. 陪产者给接诊人员说明：孕周、何时开始疼／流水、有没有出血、胎动是否改变、基础疾病、过敏和用药。
3. 检查会帮助医护了解妈妈和胎儿状态，可能包括血压、体温、胎心监测、宫缩和宫颈评估。检查前可以请医护解释目的。
4. 找到呼叫铃和厕所，确认谁负责沟通；妈妈疼痛时，一次只问一个问题，让她有时间回答。

### 不懂产程，也能知道现在在做什么

| 阶段 | 身体和医护正在处理什么 | 妈妈可以做什么 | 陪产者负责什么 |
|---|---|---|---|
| 等待宫口逐渐打开 | “开指”是对宫颈扩张的俗称，由专业检查判断 | 告诉医护疼痛、头晕、恶心和其他不适；按允许范围休息、换姿势，提出镇痛需求 | 保持安静、按她愿意的方式陪伴，协助呼叫医护 |
| 宝宝娩出 | 医护结合宫口、胎儿状态指导用力和姿势 | 跟随现场指导呼吸和用力，不必预先练长时间憋气 | 简短鼓励，不喊“别人都行”，不自行压肚子或拉宝宝 |
| 胎盘娩出和初步恢复 | 宝宝出生后仍需处理胎盘、出血和可能的缝合 | 有明显不适立刻说，不因注意力转向宝宝而忍耐 | 留意妈妈需求，拍照、报喜放在后面 |

产程可能持续很久，也可能临时改变。每个人的进度不同，不用和别人的小时数比较。[NHS：产程说明](https://www.nhs.uk/pregnancy/labour-and-birth/the-stages-of-labour-and-birth/)

陪产者可以问：“你想要握手、擦汗，还是安静待着？”补水、进食、走动、按摩都先看本人意愿和医护许可。信息太多时，帮她记住刚才的解释，而不是替她决定。[NHS：陪产者支持](https://www.nhs.uk/best-start-in-life/pregnancy/preparing-for-labour-and-birth/tips-for-your-birthing-partner-or-partners/)

### 如果需要引产、器械助产或剖宫产

引产是用医疗方法帮助分娩启动；器械助产是在符合条件时借助器械帮助宝宝娩出；剖宫产通过手术娩出宝宝。是否需要及何时进行由医疗团队结合实际评估。

能够讨论时，询问“为什么建议现在做、预期帮助和主要风险是什么、还有什么选择、可以考虑多久”。危急时配合及时处置。妈妈能表达意愿时，应让她直接获得说明和参与决定。

计划剖宫产按医院要求禁食禁饮、用药和到院，不自行延长空腹。术后第一次起身、如厕和抱娃请护士协助，腿麻、头晕、困倦时不能独自行动。

若母婴暂时分开，确认宝宝在哪个病区、联系人、如何探视和获取信息；希望保留母乳喂养机会时，请团队教手挤奶／吸奶并制定节奏与送奶要求。没有在第一小时抱到或喂到，不代表以后无法建立亲密关系。

<a id="first-day"></a>

## 出生后 0–24 小时：先稳定、先学会、先休息

### 妈妈这边，陪护不能只盯着宝宝

医护会观察出血、子宫收缩、生命体征、伤口和排尿。配合观察，告诉护士是否头晕、胸闷、头痛、腹痛加重或尿不出。不要等血把床铺弄湿才报告出血，也不要为怕疼一直憋尿。

确认可以进食后，从能够接受的食物开始；剖宫产和麻醉后按团队安排恢复饮食，不自行套用“所有人必须排气才能喝水”等统一规则。止痛药按处方使用，不因为哺乳就硬扛或自行停药。

### 宝宝这边，第一次护理由医护带着做

稳定时尽早在医护观察下肌肤接触，帮助保温并尝试首次喂养。肌肤接触是宝宝贴在成人裸露胸前，**成人清醒、有人观察宝宝呼吸、口鼻始终可见**；妈妈困倦或受镇静药影响时请人接手，把宝宝仰卧放回独立小床，不能一起趴睡。

出生后需要检查和预防措施，包括维生素 K、听力及其他新生儿筛查、适用的预防接种；由医院实施并记录。维生素 K 用于预防出血，和后面说的日常维生素 D 不是一回事。[WHO：新生儿医疗照护建议](https://www.who.int/teams/maternal-newborn-child-adolescent-health-and-ageing/handbooks/programme-manager-s-handbook-mncah/recommendations-on-interventions-along-life-course/newborn)

健康稳定的新生儿不急着洗澡，WHO 建议首次洗澡至少延后至出生 24 小时；需要特殊处理时听医护安排。不强行搓掉皮肤上白色、乳脂样的胎脂。[WHO：照顾新生儿](https://www.who.int/tools/your-life-your-health/life-phase/newborns-and-children-under-5-years/caring-for-newborns)

### 第一次喂奶：不要独自猜是否成功

初乳是出生前后最初分泌的乳汁，量少、常偏黄，不等于“没有奶”。请护士或哺乳专业人员**看完整一次喂养**，确认宝宝能否含好、吸吮和吞咽；无法有效吃奶、过于嗜睡或有低血糖风险时，当场请医护制定摄入方案，不一味等待“开奶”。

母乳喂养开始后通常需要频繁喂，包括夜间，常见为 24 小时 **8–12 次或更多**；不要把次数当作已经吃够的证明。早期喂养信号包括醒来、舔嘴、寻觅，哭通常已经较晚。若宝宝只睡不醒，问医护如何唤醒、最长间隔多久；新生儿按需喂养不等于无限等待其自己醒来。[NHS：母乳喂养最初几天](https://www.nhs.uk/baby/breastfeeding-and-bottle-feeding/breastfeeding/the-first-few-days/)

如选择配方奶或混合喂养，请医护写明当前使用的奶、每次起始量、间隔、是否需要唤醒，以及何时调整。母乳、配方奶和混合喂养都要确保安全、有效摄入；不拿喂养方式评价妈妈。

### 这一天请两位照料者各做一次

- 在护士看着的情况下抱起和放下宝宝。
- 换一次尿布，认识尿液和黑绿色、黏稠的第一批大便——胎便。
- 完成一次实际喂养或相应支持工作，说出如何判断需要帮助。
- 演示安全放回婴儿床，知道呼叫铃在哪里。

不会就请再教：“能不能您看着我做一遍？”比只看视频更容易发现手的位置、宝宝姿势和备物问题。

<a id="first-week"></a>

## 出生后第 2–7 天：出院与回家第一周

### 出院前，拿到两份清楚的交代

**妈妈的交代**：分娩和伤口情况、所有药物名称与用法、活动限制、需要监测什么、哪天复查、出现什么情况联系谁。孕期高血压、糖尿病、明显失血或其他并发症，要有专门的复测计划，不统一等到 42 天。

**宝宝的交代**：出生和出院体重、喂养计划、黄疸评估与复测时间、尿便情况、已做／未做的筛查和接种、结果怎样查询、维生素 D 方案、下次随访日期。听力或筛查没通过／没完成时，记下复查地点和日期，不等对方主动找你。

母婴应分别达到出院条件，不为“住够一天了”自行离院。健康母婴也需要早期随访：WHO 建议出生后 48–72 小时、7–14 天和第 6 周继续获得产后照护。中国的访视与复查由当地机构安排；有黄疸、体重或喂养问题时通常需更早或更密集。[WHO：产后照护时间](https://www.who.int/news/item/30-03-2022-who-urges-quality-care-for-women-and-newborns-in-critical-first-weeks-after-childbirth)

### 回家第一晚，只做必须的事

1. 先确认独立小床可用、手机有电、急救和医院电话可找。
2. 按出院方案喂养，记录最近一次喂奶和尿布；不用马上给宝宝洗澡或接待亲友。
3. 给妈妈准备饭、水、药和卫生巾，帮助她安全如厕。
4. 明确现在谁负责，另一人什么时候接手。妈妈需要亲喂时，伴侣可负责抱来、换尿布、喂后安抚和放回床，让她尽快继续休息。
5. 睡前再次检查宝宝呼吸通畅、仰卧、床面空，不把“有大人在旁边”当作同床睡的安全保证。

### “吃够了吗”要同时看过程、排泄和体重

| 时间或观察 | 可以期待的变化 | 下一步 |
|---|---|---|
| 出生最初两天 | 尿量尚少，逐渐增加；开始排胎便 | 记下来给医护看。出生满 24 小时仍没观察到排尿或胎便，应联系医疗团队确认，不自行通便 |
| 第 3–4 天 | 湿尿布增多，大便由黑绿色逐渐过渡 | 若几乎不变、宝宝吸吮差或黄疸加重，当天评估喂养 |
| 第 5 天起 | 乳汁摄入建立后，通常每天至少约 6 片明显湿的尿布 | 这是参考，不是脱水排除试验；明显少于预期或较自身减少时及时联系儿科 |
| 每次喂养 | 能有效吸吮、吞咽，部分喂后能放松 | 持续疼痛、总含不住、叫不醒、反复吃几口就无力，应请专业人员观察 |

一次倒入少量清水到干净尿布里，可以帮助你认识“湿了”的重量和触感。不要为了凑湿尿布给宝宝补白水。[NHS：怎样判断奶量足够](https://www.nhs.uk/baby/breastfeeding-and-bottle-feeding/breastfeeding-problems/enough-milk/)

出生后几天体重可能下降，随后应回升；许多宝宝在 7–14 天恢复出生体重。**下降超过出生体重的 10% 需要进一步评估，但没有达到 10% 也不能据此说安全。** 按医护安排称重并看趋势；未按预期回升、尿少或精神差要提前联系，不靠自己加浓奶粉解决。[AAP：出生后 3–5 天评估](https://www.aap.org/en/patient-care/newborn-infant-and-early-childhood-nutrition/newborn-and-infant-health-assessment-and-promotion/first-office-visit-3-5-days/)

### 黄疸：要有测量和复查时间

黄疸是皮肤、眼白等发黄，常涉及血中胆红素升高。新生儿比较常见，但是否需要治疗取决于出生后小时数、孕周、测量结果及风险。家长负责发现变化和按时复测，不自行判断“生理性”。

继续执行有效喂养计划，出现[前面的急症信号](#safety)立即就诊。不要用晒太阳、葡萄糖水、草药或自行停母乳替代评估、光疗。尿色深、大便浅白、黄疸加重或迟迟不退，都要联系儿科。[NHS：黄疸与治疗](https://www.nhs.uk/conditions/jaundice-in-babies/)

### 这些小变化可能常见，但要一起看宝宝状态

| 你可能第一次看到的现象 | 状态良好时怎样处理 | 什么情况不能只当正常 |
|---|---|---|
| 打嗝、偶尔打喷嚏、伸懒腰或突然张开手臂 | 可以先停下刺激、抱稳观察；不灌水止嗝，不把四肢绑直 | 呼吸费力、发热、持续有节律地抽动或反应变差 |
| 皮肤有胎脂、少量干燥脱皮 | 轻柔清洁，不强行搓掉；拿不准时请医护看 | 明显红肿、渗液、大片水疱或同时精神差 |
| 头顶有一块摸起来较软的地方 | 叫“囟门”，是颅骨尚未闭合处；可以轻柔清洗，不按压或碰撞 | 明显持续隆起或凹陷，尤其伴发热、呕吐或尿少时及时就医 |

这些例子帮助减少第一次见到时的惊慌，不能用于排除疾病。行为参考 [NHS：新生儿常见变化与异常](https://notts.icb.nhs.uk/your-services/childrens-health-and-wellbeing/concerned-your-newborn-baby-is-unwell-less-than-3-months/new-baby-whats-normal-and-whats-not/)，皮肤和囟门参考 [NHS：认识你的新生儿](https://www.nhs.uk/pregnancy/labour-and-birth/getting-to-know-your-newborn/)。黄疸仍按上面的测量与复查流程处理。

### 访客少一点，感染机会也少一点

接触宝宝前洗手，发热、咳嗽、腹泻或近期生病者推迟探访；家人有口唇疱疹时不亲宝宝，不让疱疹接触其皮肤。哺乳者乳房出现疱疹时，应立即咨询医生，患侧乳房及其挤出的奶暂不用于喂养，按专业安排保护泌乳和宝宝。不要让宝宝在人群中轮流传抱。[NHS：新生儿疱疹预防](https://www.nhs.uk/conditions/neonatal-herpes/)、[NHS：探访与手卫生](https://www.gloshospitals.nhs.uk/our-services/services-we-offer/maternity/after-your-baby-is-born/keeping-your-baby-safe-think-hands-and-no-kisses-thanks/)

约好探访时间和时长，请客人带饭、洗碗或采购，不让妈妈起床招待。家中和车内保持无烟，不在婴儿身边吸烟或使用电子烟。

下面这些操作从第一周开始会反复用到。先掌握当前要做的一项，不必一次练完。妈妈的伤口和身体护理也从出生当天开始，回家后即可使用后面的[恢复期护理](#weeks-two-six)，不必等到第二周。

<a id="holding"></a>

## 随手操作一：抱起、放下、交给另一个人

新生儿还不能稳定控制头颈。手要托住的是头颈和身体，不能只拎腋下或拉手臂。

1. **先准备自己**：洗手，放下手机和热饮，坐稳或站稳；第一次可以坐着练，让熟练成人在旁边看。
2. **抱起**：一手从头后滑入，托住后脑和颈部；另一手托住臀部和背部。让宝宝靠近你的身体，再整体抬起。
3. **在怀里**：头颈有支撑，口鼻露出，下巴不被压向胸口，不让脸埋在衣服或乳房里。
4. **放下**：弯腰让宝宝贴近床面，托着头颈和躯干缓慢放成仰卧；确认身体已经有支撑，再撤手。
5. **交接**：接的人先托好头颈和臀背，说“我接稳了”，原来的人再松手。不隔着桌子或热食传递。

穿衣可先把袖口套在自己的手上，再轻轻带宝宝的手穿过；脱衣先退出手臂，再处理头部，始终托住头颈。不能拖拉手指和关节。不确定动作时请护士现场纠正。图文延伸：[抱新生儿](0-3岁/日常护理/holding-newborn-01.md)。

<a id="feeding"></a>

## 随手操作二：一次完整的喂奶

### 亲喂：舒服的姿势和有效含接

“含接”指宝宝含住乳头和周围部分乳晕来吃奶，不是只吸乳头尖。

1. 先让妈妈坐稳、背部有支撑；把宝宝整个身体转向妈妈，头和身体成一条线，不歪着脖子吃。
2. 托住颈肩和背，让鼻尖大致对着乳头；轻触上唇，等嘴张大，再把宝宝贴近，以下巴先靠近乳房。
3. 观察嘴张得大、脸颊没有明显凹陷、能有节律地吸吮吞咽，口鼻不被遮住。
4. 如果持续疼、夹咬感明显或乳头被压扁，用干净手指从嘴角轻轻解除吸力，再调整；不硬拔乳头、不靠忍痛“磨出来”。
5. 让宝宝有效吃完一侧，再按其信号提供另一侧；不拿每侧固定分钟数判断已经吃足。

含不好、看不见吞咽、总在乳房上睡过去或妈妈破皮出血，需要面对面喂养评估。[NHS：含接四步](https://www.justonenorfolk.nhs.uk/media/d31oyrpe/p2p-positioning-and-attachment.pdf)

### 瓶喂：让宝宝控制停顿

1. 核对奶的种类、准备时间和温度，成人清醒坐稳，把宝宝半直立抱住并托好头颈。
2. 用奶嘴轻碰上唇，等他主动张嘴；奶瓶接近水平、略微倾斜，让奶嘴内有奶但不靠重力不断灌入。
3. 留意吞咽和呼吸，宝宝停吸就给停顿；咳嗽、漏奶多、吞咽急促时先停止，检查姿势与奶嘴流速。
4. 转头、闭嘴、停止吸吮时不强塞。不能垫着奶瓶让他自己吃，也不能平躺灌奶或边睡边无人看管地喂。
5. 按[保存规则](#milk-safety)处理剩奶，拆开奶具清洗。

具体起始量和最长间隔按宝宝年龄、体重及出院计划调整，不用“别人每顿喝多少”来追量。持续喂不进、喂后仍明显不适或摄入不足时请儿科评估。[NHS：瓶喂操作](https://www.nhs.uk/baby/breastfeeding-and-bottle-feeding/bottle-feeding/advice/)

### 喂后：需要时拍嗝，困了安全放回床

宝宝不舒服时，可以托稳头颈竖抱，轻轻抚背或拍背。不必每次拍出声音，也不必为等一个嗝长时间抱着。少量奶从嘴角溢出、宝宝舒服且生长正常时通常先观察；绿色、带血、喷射呕吐或精神差按安全区处理。

**拍不出嗝也不能改成趴睡、侧睡或垫高床头。** 回到平坦床面仰卧睡。更多图文：[喂养实操](0-3岁/日常护理/feeding-guide-01.md)、[拍嗝](0-3岁/日常护理/burping-guide-01.md)。

## 随手操作三：配方奶、储奶和奶具清洁

### 配方奶：先看产品是什么，再冲调

“婴儿配方奶”是适合婴儿营养需要的产品，不是普通奶粉、成人奶粉、鲜牛羊奶、米汤或自制混合物。特殊医学用途配方须由医生指导使用；不要因一次哭闹就换“抗敏”“舒适”奶。

1. 洗手，清洁台面，准备已清洁消毒的奶瓶，检查产品适龄、密封和有效期。
2. **先量水，再加粉**；用本罐配套量勺，按标签比例加平勺。不多加粉“顶饿”，不多加水“去火”，不掺糖或米粉。
3. **粉状配方奶不是无菌的。** 对不满 2 个月、早产或免疫功能较弱的宝宝，CDC 建议额外防菌措施：把安全饮用水煮沸，约等 5 分钟，趁水仍很热、约 70°C 时混合奶粉，再冷却到可入口温度。不同水量和容器降温速度不同，不能认为“等过五分钟”就保证温度正确。这个温度用于冲调，不是喂入口的温度。
4. 奶瓶盖紧后冷却，避免外面的水进入；腕内侧试温，温而不烫。冲奶时先把宝宝交给别人或放在安全小床，不一手抱娃一手倒热水。不用微波炉。
5. 现配现喂最易管理。一般须在配好后 2 小时内、开始喂后 1 小时内用完，两个截止时间取更早者；喝剩的丢弃。不要放温奶器保温一夜。

水温处理随年龄、水质和产品而有差异；**标签低温要求与新生儿防菌建议冲突时，不自行折中**，产前或出院前请儿科确认可执行方案，必要时讨论合适的即饮液体配方。即饮型不再加水，浓缩液体型则不同，必须认清标签。[CDC：配方奶冲调与保存](https://www.cdc.gov/infant-toddler-nutrition/formula-feeding/preparation-and-storage.html)

### 挤出的母乳：标时间，冷藏优先

以下为家庭中健康足月宝宝、清洁采集与可靠温控下的 CDC 参考，早产或住院宝宝遵守医院规则：

| 奶的状态 | 保存或使用时限 |
|---|---|
| 新鲜挤出，室温不高于 25°C | 最长 4 小时；炎热环境及时冷藏，不照搬上限 |
| 新鲜挤出，冷藏不高于 4°C | 最长 4 天，放冰箱内部，不放门边 |
| 冷冻不高于 −18°C | 约 6 个月内使用更好，最长 12 个月 |
| 冷冻奶在冰箱里完全化开 | 从完全化开起算，24 小时内使用 |
| 已回到室温或温热过 | 2 小时内使用 |
| 宝宝喝剩的母乳 | 喂完后 2 小时内使用；同时受更早的保存期限限制，超时丢弃 |

容器写上挤出日期和时间，少量分装。温水中隔容器加温即可，不煮、不微波、不把解冻奶重新冷冻。储存时间不清楚时不要凭闻起来正常判断。[CDC：母乳储存和使用](https://www.cdc.gov/breastfeeding/breast-milk-preparation-and-storage/handling-breastmilk.html)

### 清洁不是用开水烫一下

每次使用后拆开奶瓶、奶嘴、连接环和接触乳汁的吸奶器部件；用专用清洁盆、刷具及适用清洁剂洗去奶垢，流水冲净，按设备说明进行蒸汽或其他适用消毒，干净处晾干、保护存放。不拿擦碗布擦里面，也不用嘴试奶嘴是否通畅。不同材料的耐热性和消毒程序不同，先读说明。[NHS：奶具清洗消毒](https://www.nhs.uk/baby/breastfeeding-and-bottle-feeding/bottle-feeding/sterilising-baby-bottles/)

<a id="sleep"></a>

## 随手操作四：每一次睡眠都做相同的安全检查

**仰卧、独立、平坦坚实、床面空。** 白天小睡和夜里都一样，直到一岁仍要每次仰卧放下。

- 至少前六个月同室不同床。宝宝床上没有枕头、松散被褥、床围、玩偶、围嘴、安抚巾和定位垫。
- 不因吐奶而垫高或侧放；婴儿窝、沙发、成人胸口和倾斜躺椅不能代替睡眠床面。
- 成人困倦时先把宝宝放回小床，再休息；尤其避免抱着在沙发、椅子上睡着。把宝宝抱到成人床上喂奶后，照料者入睡前放回其独立小床。
- 不捂头脸、不使用加重睡袋；摸胸背判断是否过热，不能只因手脚凉就不停加衣。
- 襁褓不是必需品；若使用要仰卧、不勒胸和髋部，**一出现尝试翻身的迹象就停止包裹**，不用等到某个月龄。
- 能熟练双向翻身后，仍仰卧放下，通常不必整夜反复翻回；床面保持空。只会单向翻或有医疗情况时请儿科给具体安排。

这些做法依据 [AAP：安全睡眠](https://www.healthychildren.org/English/ages-stages/baby/sleep/Pages/a-parents-guide-to-safe-sleep.aspx)。睡醒、睡短、放下就醒的处理见[新生儿睡眠](0-3岁/日常护理/newborn-sleep-01.md)，不靠少喂奶或强行熬着不睡来“训练整觉”。

<a id="diaper"></a>

## 随手操作五：换尿布并看一眼皮肤和排泄

1. 先备好新尿布、温水与柔软清洁用品、垃圾袋，洗手。打开前就把干净尿布展开。
2. 在安全平面上放好宝宝，始终防跌落；解开旧尿布，先清走大便。
3. 轻轻从前向后清洁，尤其避免把肛门附近的污物带向尿道；每擦一次换干净面。男宝宝不强行翻包皮，女宝宝只轻柔清洁外部，不往阴道内擦。
4. 轻拍干皮肤褶皱；有尿布疹时可按适用产品薄涂屏障膏，不扑爽身粉、不自行用激素或抗真菌药。
5. 换好新尿布，松紧合适，脐带未脱落时把前缘折到脐下；清理用品后再次洗手。

有大便及时换，尿湿时也及时处理。前几周便便频繁常见；之后部分母乳宝宝排便间隔可能延长，**便软、吃得好、状态正常**与干硬便、腹胀、拒奶不是一回事。不要为一天没排便就插肥皂、棉签或频繁刺激肛门。白灰便、明显血便、异常呕吐或精神差要就医。[NHS：换尿布与排泄观察](https://www.nhs.uk/baby/caring-for-a-newborn/how-to-change-your-babys-nappy/)

进一步操作见[换尿不湿](0-3岁/日常护理/diaper-changing-01.md)。拍摄异常便便给医生看可以帮助沟通，但不能延误就诊。

<a id="bath"></a>

## 随手操作六：洗澡、脐带和日常清洁

### 第一次在家洗澡

不用每天全身洗，先保持脸、颈部褶皱、手和尿布区清洁。脐带未脱落时，擦浴更容易保持脐部干燥；第一次请熟练成人协助。

1. 选宝宝不太饿、不刚吃饱、不困得大哭的时候；关好直吹风，把毛巾、尿布、衣物全放手边。
2. 先调好水再放宝宝，充分混匀，用浴温计确认约 37°C、温暖不烫，再用肘内侧复核有没有局部烫水；不在宝宝已经入盆后加热水。早产或体温不稳宝宝先按医疗团队要求处理。
3. 一手稳定托住头肩和上臂，另一手清洗，头和口鼻始终高于水面；初期清水通常就够。
4. 洗完立刻包好、轻拍干，包括颈下、腋下和腿根，穿上干净衣物。
5. 电话响、有人敲门或忘拿东西时，抱宝宝一起离开；**哪怕只有一点水，也不能把宝宝单独留在盆里一秒钟**。浴网、浴椅不能代替成人的手和照看。

步骤依据 [NHS：给宝宝洗澡](https://www.nhs.uk/best-start-in-life/baby/baby-basics/caring-for-your-baby/bathing-your-baby/)，水温参考 [NHS 新生儿洗浴指导](https://neonatalnetworkssoutheast.nhs.uk/professionals/guidelines/tvw-guidelines/skin-integrity/)。

### 脐带：保持清洁干燥，让它自己掉

脐带残端是出生时剪断后留下的一小段，会变干、变深色并自行脱落。每天看周围皮肤，弄脏后轻柔清洁并擦干；不拉扯、不贴硬币、不撒粉、不随意涂油药。普通情况下无需常规酒精护理；医院因特殊情况给了方案则照医嘱执行。

脱落附近偶有几滴血可以观察，持续出血、红肿、脓液或臭味需联系医生。超过约三周仍未脱落也应咨询。[AAP：脐带护理](https://www.healthychildren.org/English/ages-stages/baby/bathing-skin-care/Pages/Umbilical-Cord-Care.aspx)

### 不需要做的“特殊清洁”

不挤新生儿乳头，不擦破口腔里的白点，不用棉签深入鼻孔和耳道，不剃眉毛或为“长得更好”剃胎发。指甲长了可在光线好、宝宝安静时用婴儿指甲锉或工具小心处理。眼睛明显红肿或有脓性分泌物时联系医生，不滴母乳或自行用眼药。更多见[洗澡与脐带护理](0-3岁/日常护理/bathing-care-01.md)。

<a id="crying"></a>

## 随手操作七：哭闹、测温和求助描述

### 哭了，按这个顺序看

1. **先看安全**：呼吸、颜色、反应是否正常，有没有发热、受伤、异常呕吐。出现红旗先就医。
2. **看基本需要**：是否有饥饿信号，尿布是否脏湿，衣服是否勒住，胸背是否过热，是否困了。
3. **一次试一种安抚**：抱稳、轻声说话、在怀里小幅平稳移动，或转到安静环境；看看是否舒服一些。不猛烈摇、不反复颠头。
4. **仍不行就求助**：突然与平时不同的哭声、长时间无法安抚、明显疼痛或同时吃得少，不一概解释成“肠绞痛”。

成人已经愤怒、手抖或快失控时，把宝宝仰卧放进安全空床，短暂离开缓一缓并联系能接手的人，稳定后及时回来查看。安全放下后哭一会儿，比失控抱着安全；这不是让新生儿长期哭着不管。展开排查见[哭闹快速排查](0-3岁/日常护理/crying-checklist-01.md)。

### 数字体温计怎么用

出院前请护士演示本地推荐的测温方式。常见腋下测量是擦干腋下，把探头贴在腋窝皮肤，轻拢手臂，按仪器要求等到读数；不要隔着衣服测。写下测量时间、部位、温度和宝宝状态。

不要用手摸额头代替体温计，不自行给腋温加减一个固定数“换算”直肠温度。六个月以内耳温读数可能不可靠；直肠测温虽更接近核心体温，但无操作指导不要自己硬试，更不能为取得直肠数值拖延求助。[AAP：婴儿测温与发热](https://www.healthychildren.org/English/health-issues/conditions/fever/Pages/Fever-and-Your-Baby.aspx)

不要酒精擦浴、捂汗，或自行给婴儿用成人药、止咳感冒药、抗生素。确有处方时用配套口服注射器量取，核对药名、浓度、每次毫升数和时间，两人交班避免重复给药。

### 打电话不用会说医学术语

可以照这个顺序说：“宝宝出生第几天／几个月，是否早产；从什么时候开始怎样不对；现在能不能叫醒、呼吸和脸色怎样；最近一次吃奶和尿尿何时；体温多少、在哪测的；我们已经做了什么。”妈妈就医时同样报告产后第几天、出血、疼痛、发热及用药。

不知道的就说不知道。不必先录完视频、算完所有奶量才求助。

<a id="weeks-two-six"></a>

## 第 2–6 周：妈妈恢复也是照料任务

“产褥期”通常指产后约六周的恢复阶段，但身体和心理恢复可以更久。42 天是一个复查节点，不是所有人必须恢复到孕前状态的期限。

### 每天做一次简短的身体检查

问妈妈：今天出血和昨天比怎样？疼痛有没有加重？能正常吃喝、排尿排便吗？有没有头痛、胸闷、发热或伤口问题？能获得休息吗？出现[安全信号](#safety)直接求助。

| 问题 | 常见变化与家庭护理 | 需要联系医护的变化 |
|---|---|---|
| 恶露 | 产后经阴道排出的血液和分泌物，通常数周内逐渐减少、变淡；用卫生巾观察并勤换 | 突然增加、大血块、恶臭、伴发热或严重腹痛；急症见前文 |
| 会阴伤口 | 会阴是阴道口和肛门之间区域；撕裂或侧切后可能疼。按医嘱用清水轻柔清洁、拍干，穿宽松衣物 | 越来越痛、红肿、脓液、伤口裂开 |
| 排尿和排便 | 多样饮食、足量饮水、适度走动，不憋尿、不屏气硬用力；顽固便秘请医生帮助 | 尿不出、明显尿痛、排便失控或疼痛持续 |
| 漏尿和下坠感 | 常见不等于应一直忍；记录发生情境，评估盆底功能 | 持续漏尿、明显下坠或疼痛，联系产科／盆底康复专业人员 |

可以在身体允许、有人防滑协助下淋浴、刷牙洗头，伤口护理遵守具体医嘱；不需要整个恢复期不洗澡、不通风。恶露未尽和复查前不用卫生棉条，不做阴道冲洗。[NHS：产后身体护理](https://www.nhs.uk/pregnancy/labour-and-birth/your-body/)

### 剖宫产还要保护腹部伤口

按出院要求处理敷料、洗澡和拆线，保持伤口清洁干燥，不擅自涂药、热敷或用束腹带勒紧。起床时可先侧身，用手支撑缓慢坐起；请伴侣把宝宝递来，减少反复弯腰搬抬。

在医护允许下逐步短距离走动，避免长期卧床；不要急着做卷腹、跑跳、搬重物或开车。恢复活动取决于疼痛、伤口和功能，不能只看满没满六周。伤口恶化、腿肿痛、胸闷气短要及时就医。[NHS：剖宫产恢复](https://www.nhs.uk/tests-and-treatments/caesarean-section/recovery/)

### 乳房护理：不靠暴力“通乳”

乳房变满、胀和漏奶可能随泌乳发生；持续乳头疼痛先检查含接。出现局部红、热、痛、硬结时，联系哺乳支持，照正常需求喂养，必要时少量手挤缓解不适；冷敷可用于减轻不适，皮肤与冷源之间有保护。

不要深揉硬块、暴力推拿、反复“排空”，也不要突然停止所有喂养。出现发热或寒战、红痛加重、全身不适时当天联系医生，状态差按急症处理。不哺乳者胀痛，也应请医护提供渐进处理方案。[NHS：乳腺炎与居家措施](https://www.nhs.uk/conditions/mastitis/)

<a id="nutrition"></a>

### 恢复期吃什么：普通、充足、多样、吃得到

不需要一张强制的“第几天只能喝什么汤”食谱。可以按食欲分成三餐和适量加餐，既吃主食，也吃蔬果和蛋白质食物；汤可以喝，但不应挤掉正餐。没有过敏或明确医疗原因，不因哺乳就把鱼、蛋、奶、豆类、蔬菜水果一概忌掉。

**下面是家庭配餐示例，不是针对疾病的营养处方；份量按饥饿感、体型、活动和医生要求调整：**

| 一餐怎么搭 | 可替换的普通食物 |
|---|---|
| 早餐：主食＋蛋白质＋蔬果 | 燕麦或馒头，鸡蛋和奶／无糖酸奶，洗净的水果 |
| 午餐：主食＋肉鱼蛋豆＋蔬菜 | 米饭，鱼或瘦肉／豆腐，一到两样蔬菜 |
| 加餐：饿了再补 | 奶或无糖酸奶、全麦面包、水果等；过敏时换适合自己的食物 |
| 晚餐：继续完整吃一餐 | 杂粮饭或面，鸡肉／豆类，蔬菜；可配一碗清淡汤 |

伴侣可以一次准备几份饭菜并安全冷藏，负责加热到充分热透、及时送到。让妈妈每天稳定吃到几餐，比研究昂贵补品更实用。

哺乳时营养需求会增加，尤其应留意蛋白质、铁、钙、碘和维生素等来源。明显失血／贫血按处方补铁，素食或严格忌口者请医生评估维生素 B12 等需求；不凭“补得多更好”叠加多种补充剂。哺乳期通常无需排除整类食物。[CDC：哺乳期饮食](https://www.cdc.gov/breastfeeding-special-circumstances/hcp/diet-micronutrients/maternal-diet.html)

咖啡因可采用 NHS 较谨慎的建议：每天总量不超过 200 mg，咖啡、茶、可乐和巧克力都计入，按标签或商家公布含量核算，不能把“一杯”当固定剂量。新生儿和早产儿更敏感；宝宝出现明显烦躁或睡眠受影响时进一步减少并咨询。[NHS：哺乳饮食与咖啡因](https://www.nhs.uk/baby/breastfeeding-and-bottle-feeding/breastfeeding-and-lifestyle/diet/)

水杯放手边、按口渴饮水，不强迫灌大量汤水。避免酒精“催乳”，不用来路不明的中草药和保健品。糖尿病、高血压、肾病、甲状腺病或严重贫血需要个体营养和用药方案，不能套这张示例表。

### 身体活动、亲密关系与避孕

在身体允许范围逐步增加轻柔活动，疼痛、出血明显增加就停止并咨询。盆底是支撑膀胱、子宫等的肌肉群，训练需要学对收缩和放松；有疼痛、下坠感、严重撕裂或仍留置尿管时先评估，不自行追求次数，也不要通过反复中断排尿来练习。[UCLH：产后活动与盆底护理](https://www.uclh.nhs.uk/patients-and-visitors/patient-information-pages/advice-and-exercise-following-childbirth)

恢复性生活要考虑本人意愿、疼痛和伤口恢复。月经没来、还在哺乳并不自动等于不会怀孕，产前或产后就可以与医生讨论适合的避孕方法。不把复查日期当作必须恢复性生活的时间。[NHS：产后性生活与避孕](https://www.nhs.uk/baby/support-and-services/sex-and-contraception-after-birth/)

### 情绪照护从今天开始，不等“扛不住”

产后短暂想哭、情绪波动可能在两周内减轻；持续、加重、失去兴趣、强烈自责、明明有机会也睡不着或难以照料时，应尽早联系专业人员，**不必为了满足“两周”才求助**。父亲和伴侣也可能出现抑郁、焦虑。[NHS：产后抑郁](https://www.nhs.uk/mental-health/conditions/postnatal-depression/)

幻觉、妄想、明显混乱、异常兴奋并几乎不需要睡眠，尤其突然出现时，要立即医疗评估；有危险或无法保证安全时急救处理。[NHS：产后精神病](https://www.nhs.uk/mental-health/conditions/post-partum-psychosis/)

每天用一句具体的话替代“你想开点”：“下一次换尿布到放回床我来做，你现在吃饭／休息。”更详细的支持见[新手父母心理调适](父母自身/产后调适/parental-wellbeing-01.md)、[睡眠剥夺应对](父母自身/产后调适/sleep-deprivation-01.md)、[产后抑郁识别与应对](父母自身/产后调适/postpartum-depression-01.md)。

### 复查带什么、问什么

带出院记录、药物清单、疑问和少量有代表性的观察。妈妈问伤口、出血、疼痛、情绪、盆底、性生活和避孕；有孕期疾病的按要求做专项随访。宝宝问喂养、体重身长头围趋势、黄疸、筛查结果、接种和下一次儿童保健时间。

中国孕产期保健规范列有产后 3–7 天及 28 天访视、42 天母婴健康检查；实际预约和额外随访请向分娩医院与社区确认，**不能用固定节点推迟有症状者就诊**。[国家卫生健康委：孕产期保健工作规范](https://www.nhc.gov.cn/zwgk/wtwj/201304/84ec2d5d37a54398ace49df48ca91c83.shtml)

<a id="months-one-three"></a>

## 满月后至 3 个月：先回应，再观察节律

### 照料重点仍是吃、睡、排泄和家庭休息

宝宝夜醒、傍晚更容易哭、连续一段时间频繁吃奶，都可能出现。先结合精神、尿量和生长看，不单凭“又要吃了”判断奶不好，也不把所有哭闹都当成饿。

白天清醒时保留自然光和正常家居声音，夜里减少灯光、说话和逗玩。不要为了夜里多睡强行取消白天睡眠，也不要擅自取消仍需要的夜奶。到现在还需要抱哄并不表示“惯坏了”。

按儿童保健安排监测体重、身长和头围，按接种门诊预约带好接种本。发热、拒奶或精神差不能因为“刚打过疫苗”就忽略，尤其三个月及以下仍遵守前面的发热求助规则。

### 维生素 D：出生后就该问清，不等晒太阳补

出院前确认具体产品、每滴或每粒的含量、每天使用多少、是否与其他补充剂重复。中国国家卫生健康委喂养核心信息提出出生起在医生指导下补充维生素 D 400–800 IU／日；CDC 对母乳或混合喂养婴儿的常用建议是 400 IU／日。**两者是不同指南口径，不是把剂量相加**；家庭执行儿保医生确认的一个方案，全配方喂养也要结合实际摄入核算。

不要自行加钙、鱼肝油或叠加 AD 和 D，不以日晒替代补充。健康婴儿六个月内主要吃母乳或适龄配方奶，通常不需额外喝水、果汁或米汤；特殊疾病另听医嘱。[国家卫生健康委：婴幼儿喂养核心信息](https://www.nhc.gov.cn/fys/c100078/202007/6a8527b3e5fa48288448ca39ef6254e3.shtml)、[CDC：维生素 D](https://www.cdc.gov/infant-toddler-nutrition/vitamins-minerals/vitamin-d.html)

### 第一个月的成长引导：照料本身就是互动

- 换尿布前说“我要帮你换干净的了”，动作前稍停，保持轻柔。
- 清醒舒服时抱着让宝宝看你的脸，轻声说几句，等一等；不需要持续放音乐或拿卡片追着看。
- 他看开、打哈欠、皱眉或哭了就暂停，先照顾困、饿或不适。

这些是把回应放进日常的示例，不是每天必须完成的训练课程。

### 满 2 个月前后：留出“你一声、我一声”的时间

清醒且舒适时，面对宝宝笑、说话，等他看你或发声，再回应。常见可观察变化包括看脸、对声音有反应、出现哭声以外的声音、对逗引微笑、趴着时尝试抬头。你可以记下一两个自然发生的例子，不要求每次表演。

到了相应月龄还没有出现某些变化、有听力或视力担忧，或任何已会技能消失，及时与儿保／儿科讨论，不靠增加训练量处理。CDC 清单用于观察，不能代替发育筛查。[CDC：2 个月发展观察](https://www.cdc.gov/act-early/milestones/2-months.html)

### 清醒趴玩怎么开始

从回家后健康稳定、清醒且有人全程看护时开始。成人在宝宝旁边，把他放在安全、平坦的地垫上，脸前留空；俯下身与他对视。可以先短到一分钟以内，耐受后再增加，少量多次，不为凑时间让他持续哭。

AAP 给出的起步参考是每天 2–3 次、每次 3–5 分钟，逐步到约 7 周每天累计 15–30 分钟；这不是新生儿第一天必须完成的作业。避免刚吃饱就趴；困了、脸贴住垫子或明显不适就停止，睡觉仰卧。特殊健康情况先问医生。[AAP：仰卧睡、清醒趴玩](https://www.healthychildren.org/English/ages-stages/baby/sleep/Pages/Back-to-Sleep-Tummy-to-Play.aspx)

不拉着手臂“练抬头”，不压住后背，不把枕头堆在周围强行坐起。身体两侧活动明显不对称、头总偏向一边时请专业人员检查。继续阅读[安全依恋](0-3岁/认知与心理/attachment-01.md)、[粗大动作](0-3岁/身体能力/gross-motor-01.md)。

<a id="months-three-six"></a>

## 3–6 个月：给安全空间，让宝宝主动探索

### 接近 4 个月：头更稳、手更忙、交流更多

常见观察包括抱着时头部更稳定、手到嘴边、挥手碰玩具、咿呀发声、对互动轻笑。地面清醒活动时，把轻巧、完整、适龄且无法整个塞入口中的玩具放在看得见、够得着的位置，等他尝试，不把手硬掰开塞玩具。

用他说出的声音回应，再停下来等；读布书或纸板书时只说眼前看到的东西，不必读完一页。宝宝转开、烦躁或困了就结束。[CDC：4 个月发展观察与活动](https://www.cdc.gov/act-early/milestones/4-months.html)

### 接近 6 个月：伸手拿、放嘴里、与你来回发声

可以留意宝宝是否认识熟悉的人、笑、与你轮流发声、伸手取玩具、用嘴探索、趴着用手臂撑起或从趴翻到仰卧。有人会更早出现某些动作，有人顺序不同。

每天有短暂的地面玩耍：把玩具放在身前或侧前方，成人在旁看护，让他自己够、抓、转向。需要支撑坐时用成人双手稳稳支持，不能用枕头围住后离开，也不要求六个月必须独坐。[CDC：6 个月发展观察与活动](https://www.cdc.gov/act-early/milestones/6-months.html)

**月龄是观察入口，不是达标表，也不是一律“再等等”的理由。** 早产宝宝请儿科指导使用矫正月龄，例如早生约八周、实际四个月，发育观察常参考约两个月；生长、接种与医疗安排不能自行全部顺延。[AAP：早产宝宝矫正月龄](https://www.healthychildren.org/english/ages-stages/baby/preemie/pages/preemie-milestones.aspx)

技能倒退、明显不对称、对声音和面孔反应少，或到相应月龄仍缺少所列变化，应主动申请评估。详见[发展路线图与评估框架](0-3岁/development-assessment.md)。

### 一旦可能翻身，就升级防跌落和防窒息

- 不独留在成人床、沙发或护理台上；“昨天还不会翻”不能保证今天不会。
- 地面清掉硬币、纽扣电池、磁铁、塑料袋、长绳和玩具脱落小零件；吞入或疑似吞入纽扣电池、磁铁时立即急诊，不等症状、不催吐。本文年龄段不能使用大龄儿童误吞电池时可能用到的蜂蜜措施。[AAP：误吞异物](https://www.healthychildren.org/English/tips-tools/symptom-checker/IFrame/Pages/symptomviewer.aspx?symptom=Swallowed+Foreign+Object)
- 按床具说明及时调整床板高度和停用超龄／超出活动能力限制的摇篮。
- 不用学步车、牵拉站立或被动摆姿势来赶进度；不用屏幕和背景电视替代真人互动。

白天可在适宜天气下短时间外出，准备尿布和喂养用品，避开过热、烟雾与拥挤环境；用遮阴保护，不能拿厚毯子把推车整个罩住。乘车按安全座椅说明固定，到目的地移至适合睡眠的平坦床面，不把座椅当床。

### 睡眠和喂养变化，先排查需要

有些宝宝此时更易分心吃奶、睡眠也会变化。可找安静处喂养，观察一天总体摄入、尿量和生长；短期波动不自动等于“厌奶期”，持续拒奶或增长受影响要评估。吃手和夜醒也不是提前加辅食的充分理由。

如妈妈准备返岗或增加外出，提前让另一照料者完成整次照护，在熟悉环境中练习喂养、安抚和放回床；储奶使用同一套时间规则。根据工作安排讨论挤奶与休息机会，不为提前囤奶而过度吸奶。更深入的主题见[精细动作](0-3岁/身体能力/fine-motor-01.md)、[母语与多语言互动（0–3 岁）](../../../interests/language/母语发展/0-3岁.md)、[婴幼儿屏幕管理](0-3岁/认知与心理/screen-time-01.md)。

## 接近满 6 个月：做好下一阶段交接

### 先讨论辅食准备，不在本篇展开完整食谱

“辅食”是母乳或配方奶之外逐步添加的食物，不是用来立刻替掉奶。通常在约六个月、具备相应能力时开始：头颈控制较稳，能独坐或在支持下坐好，对食物张嘴，能把食物吞下而不总用舌头顶出。不是等到长牙，也不是仅凭看大人吃饭、夜醒或体重判断。

提前和儿保医生讨论含铁食物、适合的质地、进食姿势和过敏原引入。有严重湿疹、鸡蛋过敏等情况，应更早咨询花生等食物的安全引入时机，不自行尝试或一律拖延。[CDC：何时、如何开始辅食](https://www.cdc.gov/infant-toddler-nutrition/foods-and-drinks/when-what-and-how-to-introduce-solid-foods.html)

## 家庭交接卡：睡得少的时候，把事情写简单

把下面内容复制到纸上或手机备忘录即可。出生最初几天、喂养尚未稳定或有医疗要求时可按次记录；稳定以后简化，没必要全天追踪每个动作。

| 项目 | 这一班交接时说清什么 |
|---|---|
| 宝宝 | 最近一次有效吃奶时间与方式；瓶喂时实际吃了多少；最近尿便；是否有体温、黄疸或其他变化 |
| 妈妈 | 上次吃饭喝水、药名与时间；出血和疼痛变化；接下来需要什么帮助 |
| 奶和用品 | 哪份奶先用、何时过期；奶具是否已经清洁消毒；用品放在哪里 |
| 责任 | 现在谁完整负责，另一人何时接手；什么情况下立即叫醒对方或打电话 |
| 医疗安排 | 谁在何时带谁复查，哪些结果待查询，有没有更早的个体随访要求 |

交班示例：“上一顿亲喂完成在 22:10，吞咽能听见；22:30 换过湿尿布，没有新异常。接下来我负责安抚和尿布，需要吃奶时再叫你。宝宝现在仰卧在自己的床里。妈妈的药按卡上的时间，不重复吃。”时间仅用于示范记录，不是推荐的作息表。

每周花几分钟只讨论三件事：宝宝有什么值得问医生的新变化；妈妈恢复和情绪怎样；哪项任务换人后能让家里多一点休息。需要额外支持可看[夫妻关系产后调适](父母自身/关系维护/couple-adjustment-01.md)、[代际育儿观念冲突](父母自身/关系维护/intergenerational-parenting-01.md)和[完美主义陷阱](父母自身/育儿压力/perfectionism-trap-01.md)。

今天先做一件事就够：还没出生，完成医院联系表；准备出院，请护士看你操作一次；已经回家，确定下一班谁接手。新的疑问按[时间线](#timeline)和[日常护理指南](0-3岁/日常护理/_index.md)继续找，有[安全信号](#safety)先求助。
