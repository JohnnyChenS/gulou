# 育儿指导（0–18 岁）

先从孩子当前阶段建立整体理解。阅读顺序把照料、身体、关系和学习连起来；专题用于深入已经遇到的问题，不需要先记住一串能力名称。

## 从当前阶段开始

| 当前处境 | 阅读入口 |
| --- | --- |
| 准备出生至三岁 | [十五章新手父母连续阅读](../../../paths/parenting/new-parent/_index.md) |
| 三至六岁 | [学龄前生活与游戏](3-6岁/_index.md) |
| 六至九岁 | [入学与学校生活](6-9岁/_index.md) |
| 九至十二岁 | [学习、关系与逐渐自主](9-12岁/_index.md) |
| 十二至十四岁 | [身体变化与青春期开始](12-14岁/_index.md) |
| 十四至十八岁 | [自主选择与父母支持](14-18岁/_index.md) |

孩子已经出生，可以在十五章目录里直接选择当前阶段。进入某年龄不表示此前的任务已经全部完成，也不要求父母从头补读。

## 需要查阅时

母婴异常或即时安全担忧先进入[安全与求助](quick-start.md#safety)。[照料手册](quick-start.md)提供产前至六个月的操作与随访资料；[0–3 岁照料与成长查阅](0-3岁/_index.md)按喂养、睡眠、动作、沟通等眼前问题定位文章。查阅页不承担默认下一章。

父母的休息、压力、身份和关系进入[父母与照料者支持](父母自身/_index.md)。那里既有新生儿家庭的四篇短路线，也能直接查当前问题。

孩子本人想探索兴趣，可以直接进入[不知道自己喜欢什么](../../../paths/exploration/youth/_index.md)，不用从父母课程开始。
