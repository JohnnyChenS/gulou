# 3-6 岁发展观察框架

> 这不是一张打分表，也不是入学前的通关清单。它帮助你从真实生活中看见孩子正在发展的能力，选择一个小调整，再决定是否需要和专业人员讨论。

## 先分清三种信息

- **家庭观察**：家长、照料者和老师在日常生活中记录孩子如何玩、说、动、理解、合作和恢复；
- **发展监测**：持续关注一段时间内的变化，用具体例子和专业人员沟通；
- **正式筛查或评估**：由接受训练的专业人员使用相应工具，结合访谈、观察和孩子的完整情况进行。

CDC 说明，里程碑清单可以帮助家庭发现值得讨论的线索，但不能替代经过验证的正式发展筛查工具。没有达到某一项、出现已经会做的能力倒退，或照料者持续担忧，都可以提前咨询，不必等到下一个固定年龄。[CDC 发展监测与筛查说明](https://www.cdc.gov/act-early/about/developmental-monitoring-and-screening.html)

## 观察—调整—复盘

### 1. 只选一个真实问题

例如：“早上出门总是卡住”“和同伴玩时不会轮流”“讲故事时不愿意说”“画画或穿衣很容易放弃”。一次处理一个问题，比给所有能力打分更容易看见变化。

### 2. 记录发生的情境

写下孩子当时在做什么、和谁在一起、是否疲劳或饥饿、任务有几步、环境是否嘈杂，以及成人做了什么。不要只写“专注力差”“不合群”或“落后”，尽量记录可以看见和听见的行为。

### 3. 做一个低风险调整

可以减少一步指令、示范一次、把材料放近、给两个都能接受的选项、先预告转场，或让孩子在活动中承担一个小角色。一次只改变一两个因素，不用突然增加训练时长。

### 4. 看孩子是否更容易参与或恢复

调整后孩子是否更容易开始、继续、转换或收尾？他是否能在成人支持下恢复？没有变化不代表家长做错，也不代表需要不断加码；可能需要换策略，或把记录带给专业人员。

## 按年龄选择观察重点

年龄段是寻找观察角度的入口，不是要求孩子在生日当天完成的清单。CDC 的里程碑通常描述“多数儿童到某个年龄可以做到的事情”，仍应结合孩子的整体发展、语言环境、健康状况和生活情境理解。

### 3–4 岁：表达、假装和参与生活

| 方向 | 可以观察的变化 | 成人可以做什么 |
| --- | --- | --- |
| 沟通 | 用对话、问题、手势或动作表达需要；别人是否大多能理解他的表达 | 少测试，多把语言放进吃饭、穿衣、出门和游戏；听不清时请孩子用别的方式表达 |
| 游戏与关系 | 注意其他孩子，可能尝试加入；出现模仿和假装游戏 | 在旁边示范如何靠近、邀请、等待和退出，不强迫立刻分享或合作 |
| 认知与解决问题 | 通过重复、分类、画画、寻找和尝试理解结果 | 给足时间尝试，遇到困难时问“我们还可以试什么”，不要马上代替完成 |
| 身体与生活 | 继续练习跑跳、穿脱部分衣物、使用餐具和参与收拾 | 提供安全的活动空间和小任务，重视过程中的安全、舒适和参与 |

### 4–5 岁：想象、规则和来回合作

| 方向 | 可以观察的变化 | 成人可以做什么 |
| --- | --- | --- |
| 沟通与故事 | 说较完整的句子，讲述一天中的片段，回答关于物品用途的问题 | 读完一页后问孩子看到了什么，也接受指向、动作或简短回答；不要求复述标准答案 |
| 想象与同伴 | 在游戏中扮演角色，主动找同伴，开始注意他人的感受和规则 | 给假装游戏留出时间，冲突时先描述发生了什么，再帮助孩子提出可行办法 |
| 等待与转换 | 在成人提示下等待、按顺序做事、从一个活动转到另一个活动 | 提前预告变化，用图片或短句提示，把任务拆小，给孩子一个可以完成的收尾动作 |
| 动作与工具 | 接球、倒水、解扣、握笔、搭建或剪贴的方式继续变化 | 选择安全、适龄的工具，允许失败和重新尝试；需要帮助时只补上卡住的步骤 |

### 5–6 岁：叙述、规则和更长的共同任务

| 方向 | 可以观察的变化 | 成人可以做什么 |
| --- | --- | --- |
| 语言与对话 | 能围绕熟悉话题来回交流，讲述有先后关系的故事，回答简单问题 | 接着孩子的内容追问一小步，帮助他把时间、人物和行动说清楚，不把对话变成口试 |
| 学习与问题解决 | 在游戏或活动中保持一段投入，尝试数数、押韵、字母或符号与意义的连接 | 把前读写和前数学放进生活，用积木、购物、做饭、绘本和游戏探索，不提前刷题替代游戏 |
| 合作与规则 | 逐渐理解轮流、简单规则、他人观点和共同完成任务 | 规则保持少而清楚，必要时和孩子一起修改；关注他能否在帮助下恢复，而不是要求每次完美控制 |
| 自理与身体 | 参与更多穿衣、整理、倒水、画画、跑跳和户外活动 | 给孩子真实而安全的责任，按天气、健康和兴趣安排主动活动与休息 |

## 按能力域记录

| 能力域 | 更适合记录什么 | 不要用来做什么 |
| --- | --- | --- |
| 语言与沟通 | 理解、表达、来回对话、讲述和不同语言中的沟通方式 | 不用词汇量或一次说不清楚给孩子排名 |
| 关系与游戏 | 如何加入、邀请、轮流、假装、解决冲突和接受帮助 | 不把一次不分享或独自玩等同于社会性结论 |
| 情绪与执行 | 如何开始、等待、转换、暂停、恢复和完成任务 | 不用一场发脾气推断性格或执行功能水平 |
| 认知与前学业 | 提问、分类、记住步骤、尝试方法、连接符号与意义 | 不把识字、算数或背诵量当作入学资格 |
| 动作与自理 | 跑跳、平衡、手部工具、穿衣、进食和参与生活任务 | 不用单一动作日期给孩子贴标签 |
| 感觉与环境适应 | 哪些声音、触感、光线、拥挤或转场会影响参与，什么调整有帮助 | 不凭一种偏好诊断“感统失调”或其他发育状况 |

## 一个简单的观察记录

可以记录一到两周，也可以只记录几次关键场景。重点是具体、可比较，不是记录越多越好：

| 记录项 | 示例 |
| --- | --- |
| 日期、年龄和场景 | 4 岁 2 个月，周一早上出门；周三在幼儿园自由游戏 |
| 我看到的行为 | 听到“收玩具”后停下，看着成人，继续玩了两分钟，后来在成人拆成两步后开始收 |
| 孩子的状态 | 睡眠不足、刚从户外回来、和熟悉的照料者在一起 |
| 成人的支持 | 预告转场、减少指令、示范一个动作、给两个收纳位置选择 |
| 后来的变化 | 开始更快、仍需要提醒、情绪升级、能恢复，或没有变化 |
| 我想请专业人员帮助判断什么 | 是否需要关注听力、语言、动作、情绪或环境适应 |

## 什么时候不再继续家庭观察

建议把具体记录带给儿科、儿童保健、听力、言语语言、发育行为、心理健康或教育专业人员的情况包括：

- 已经会做的语言、动作、自理、游戏或社交沟通能力明显倒退；
- 在不同场景和照料者面前都持续很少回应、理解、表达或参与，已经影响日常生活；
- 反复出现明显的听力、视力、疼痛、动作不对称、进食或睡眠问题；
- 情绪、行为、感觉或转场困难持续影响安全、入园、同伴关系、家庭生活或孩子的舒适度；
- 孩子在多个方面长期遇到困难，或家长、老师和其他照料者都感到担心；
- 照料者直觉持续觉得不对，即使孩子已经会做一些清单上的项目。

如果出现呼吸困难、发青、意识改变、严重受伤、疑似窒息或严重过敏反应，跳过家庭观察，立即联系当地急救服务。

## 如何准备一次咨询

带上一个具体问题和两三个真实例子即可。可以告诉专业人员：

- 孩子的年龄、语言环境、健康状况和是否早产；
- 困难从什么时候开始，在哪些场景出现，是否逐渐加重；
- 孩子在什么情况下做得更好，哪些成人支持有帮助；
- 已经会做的能力有没有倒退；
- 你最希望专业人员排查或帮助什么。

家庭记录的作用是让对话更具体，不是先替孩子下诊断。如果一次咨询后仍然担心，可以询问下一步筛查、转介或复评安排。
