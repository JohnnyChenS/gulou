# 青春期（14-18岁）— 父母指导

## 先从这里开始

第一次进入本阶段，建议沿这条主线读：

1. [青春期亲子沟通](认知与心理/parent-teen-communication-01.md)：先恢复可说话、可暂停、可重新邀请的关系基础。
2. [青少年心理健康危机识别](认知与心理/adolescent-mental-health-01.md)：知道哪些变化需要专业支持，不能只归为叛逆。
3. [自主学习与兴趣深入](认知与心理/autonomous-learning-and-interest-01.md)：让青少年参与目标、资源、反馈和方向调整。
4. [升学压力与学业焦虑](认知与心理/academic-pressure-01.md)：把成绩放回睡眠、情绪和现实选择中。
5. [数字设备与网络管理](认知与心理/digital-life-01.md)：围绕功能、安全和共同规则谈数字生活。
6. [青春期叛逆与冲突应对](认知与心理/adolescent-rebellion-01.md)：区分可协商的个人领域与必须守住的安全边界。

各篇的“实战篇”是发生具体冲突时的查阅工具，不计入主线进度：沟通、冲突、学业压力和数字生活都可以在需要时打开。

## 阶段概述

14–18 岁的自主需求、学业选择、同伴关系和身体/心理状态互相影响。父母角色逐步从直接管理转为提供信息、资源、边界和在场支持；这不等于完全退出，也不等于替青少年作决定。不同家庭、学校和文化情境中的表现差异很大。

## 发展观察与安全边界

[发展路线图与评估框架](development-assessment.md)用于记录功能和支持变化，不是人格或心理健康筛查。若出现持续失眠、明显情绪低落或异常高涨、拒学、功能显著下降、自伤/自杀想法、伤人或现实安全风险，先联系可信任成人、学校和合格专业人员；紧急危险按当地急救流程处理。

## 可选专题

- 需要处理一次具体争吵：从[亲子沟通实战篇](认知与心理/parent-teen-communication-02.md)或[叛逆与冲突实战篇](认知与心理/adolescent-rebellion-02.md)进入。
- 主要是成绩或考试反应：进入[升学压力与学业焦虑·实战篇](认知与心理/academic-pressure-02.md)。
- 主要是手机、游戏或隐私边界：进入[数字设备与网络管理·实战篇](认知与心理/digital-life-02.md)。
