# 学习习惯：先让任务能开始

孩子坐在桌前却迟迟不动，可能是没听懂要求、不知道第一步、任务过长，也可能已经疲惫或紧张。先观察一次真实任务，不急着把它解释成懒惰。

本页把判断和调整过程讲完整。后面的年龄文章用于深入对应处境，不要求从学龄前一直读到青春期才可以处理眼前的问题。

## 先找到停下来的位置

请孩子用自己的话说出要做什么，再看他能不能指出第一步。例如“写作文”太大，可以先变成“说出今天想讲的一件事”。如果连题目都没理解，先解释；如果材料还没找到，先准备；如果害怕写错，先允许一个可以修改的草稿。

等待、记住步骤和转换任务，常被放在“执行功能”这个概念下。对家庭来说，更有用的问题是：哪一种提醒让孩子能参与？学龄前可能需要一次只说一个动作；年龄更大时可以一起写清单，再逐渐让孩子自己安排。

## 把任务的开始和结束都说清楚

开始信号可以是准备好材料、说清第一步，再由孩子动手。结束不是成人突然喊停，而是当前这一小部分完成后，检查哪里懂了、哪里需要帮助。任务长度根据状态调整，不用一个统一的分钟数判断专注是否合格。

如果你一直在旁催促，先试着减少一句重复提醒，换成一个具体问题：“你准备从哪一步开始？需要我帮你读题还是准备材料？”已经能独立做的部分让孩子自己完成；确实需要支持的地方也不用硬撑。

## 用反馈决定下一次怎样安排

完成后聊三件事：哪里顺利、哪里卡住、下次改什么。例如，题目已经理解却总忘记检查，可以把“回看要求”写在收尾位置。没有开始就先查启动原因，不先增加练习量。

观察的作用是辨认变化，不是给每天的表现打分。出现持续拒学、明显失眠或焦虑、健康与安全担忧时，不等一个记录周期结束再联系老师或专业人员。
