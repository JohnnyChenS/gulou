# 按问题开始

> 这是保留的问题学习辅助索引，不再是首页主入口。需要按年龄建立主线时，请从[家庭期的育儿指导](../../../stages/家庭期（25-45岁）/育儿指导/_index.md)进入规范年龄页。

如果你已经知道自己正在为什么发愁，可以直接进入对应路线。每条路线先处理一个小问题，再告诉你什么时候转回年龄路线。

| 你现在想解决什么 | 从这里开始 |
|---|---|
| 孩子很难开始、坚持或收尾 | [学习习惯](learning-habits.md) |
| 作业、阅读或学校任务总是卡住 | [学校学习](school-learning.md) |
| 不知道兴趣是真是假，或报课后想调整 | [发现兴趣](interest-discovery.md) |

如果问题不在这三类，回到[按年龄开始](../ages/_index.md)，先看当前阶段的主线。
