# 按年龄开始

> 这是保留的年龄学习辅助索引，不再是首页主入口。规范入口是[家庭期的育儿指导](../../../stages/家庭期（25-45岁）/育儿指导/_index.md)下的对应年龄页。

先选一个最接近孩子当前年龄的入口。年龄不是硬性分界；如果孩子正在经历别的任务，可以跳到更贴近当下的一步。

| 年龄 | 先关注 | 路线 |
|---|---|---|
| 0–3 岁 | 回应、共同注意、语言互动和自由探索 | [从互动开始](0-3.md)；[规范入口](../../../stages/家庭期（25-45岁）/育儿指导/0-3岁/_index.md) |
| 3–6 岁 | 提问、投入、转换、完成和再试 | [从游戏和生活任务开始](3-6.md)；[规范入口](../../../stages/家庭期（25-45岁）/育儿指导/3-6岁/_index.md) |
| 6–9 岁 | 入学适应、作业启动、阅读理解和提问 | [从学校学习习惯开始](6-9.md)；[规范入口](../../../stages/家庭期（25-45岁）/育儿指导/6-9岁/_index.md) |
| 9–12 岁 | 目标、检索、错误修正和知识组织 | [从自我调节学习开始](9-12.md)；[规范入口](../../../stages/家庭期（25-45岁）/育儿指导/9-12岁/_index.md) |
| 12–14 岁 | 计划、时间估计、反馈和压力管理 | [从学习策略开始](12-14.md)；[规范入口](../../../stages/家庭期（25-45岁）/育儿指导/12-14岁/_index.md) |
| 14–18 岁 | 自主计划、兴趣深入、项目实践和方向调整 | [从自主学习开始](14-18.md)；[规范入口](../../../stages/家庭期（25-45岁）/育儿指导/14-18岁/_index.md) |

不确定从哪里开始？先看[按问题开始](../questions/_index.md)。
