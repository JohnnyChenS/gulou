# 按年龄开始

> 这里按年龄列出家庭期育儿指导的阶段主页，不再是首页主入口。需要按行动顺序阅读时，再从阶段主页中的“深入阅读与辅助路径”进入对应的行动路线。

先选一个最接近孩子当前年龄的入口。年龄不是硬性分界；如果孩子正在经历别的任务，可以跳到更贴近当下的一步。

| 年龄 | 先关注 | 阶段入口 |
|---|---|---|
| 0–3 岁 | 回应、共同注意、语言互动和自由探索 | [进入 0–3 岁阶段](../../../stages/家庭期（25-45岁）/育儿指导/0-3岁/_index.md) |
| 3–6 岁 | 提问、投入、转换、完成和再试 | [进入 3–6 岁阶段](../../../stages/家庭期（25-45岁）/育儿指导/3-6岁/_index.md) |
| 6–9 岁 | 入学适应、作业启动、阅读理解和提问 | [进入 6–9 岁阶段](../../../stages/家庭期（25-45岁）/育儿指导/6-9岁/_index.md) |
| 9–12 岁 | 目标、检索、错误修正和知识组织 | [进入 9–12 岁阶段](../../../stages/家庭期（25-45岁）/育儿指导/9-12岁/_index.md) |
| 12–14 岁 | 计划、时间估计、反馈和压力管理 | [进入 12–14 岁阶段](../../../stages/家庭期（25-45岁）/育儿指导/12-14岁/_index.md) |
| 14–18 岁 | 自主计划、兴趣深入、项目实践和方向调整 | [进入 14–18 岁阶段](../../../stages/家庭期（25-45岁）/育儿指导/14-18岁/_index.md) |
