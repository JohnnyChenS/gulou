# 按年龄开始

选择孩子当前阶段，先建立身体、生活、关系和学习如何相连的理解。路线的章节顺序服务于父母阅读，不是孩子的发展考核。

| 年龄 | 当前阅读入口 | 怎样深入 |
| --- | --- | --- |
| 0–3 岁 | [十五章新手父母主线](../../parenting/new-parent/_index.md) | [本年龄的阅读安排](0-3.md)，以及[月龄与全部主题](../../../stages/家庭期（25-45岁）/育儿指导/0-3岁/_index.md) |
| 3–6 岁 | [学龄前连续阅读](3-6.md) | [阶段与全部主题](../../../stages/家庭期（25-45岁）/育儿指导/3-6岁/_index.md) |
| 6–9 岁 | [入学与学校生活](6-9.md) | [阶段与全部主题](../../../stages/家庭期（25-45岁）/育儿指导/6-9岁/_index.md) |
| 9–12 岁 | [学习、关系与逐渐自主](9-12.md) | [阶段与全部主题](../../../stages/家庭期（25-45岁）/育儿指导/9-12岁/_index.md) |
| 12–14 岁 | [身体变化与青春期开始](12-14.md) | [阶段与全部主题](../../../stages/家庭期（25-45岁）/育儿指导/12-14岁/_index.md) |
| 14–18 岁 | [自主选择与父母支持](14-18.md) | [阶段与全部主题](../../../stages/家庭期（25-45岁）/育儿指导/14-18岁/_index.md) |

读正文时沿默认下一章继续；想查具体操作或一个概念，再进入章末资料。各阶段中身体、情绪和学习可能不同步；遇到持续困难或倒退，不需要读完路线才能求助。

照料者自己的状态同时值得处理，进入[父母支持路线](../../parenting/parent-wellbeing.md)。已经知道具体问题时也可进入[问题查阅](../questions/_index.md)，它不要求跨年龄完成一串文章。
