# 青少年本人探索：从不知道喜欢什么到下一小步

你不需要先知道“真正喜欢什么”，才有资格开始。兴趣通常是在接触、遇到一点困难、回头比较之后逐渐变清楚的；一次试用也不决定你以后是谁。

这四章按一个可重复的过程排列：先说清你现在卡在哪里，再做一个成本可控的尝试，回看过程，最后决定继续、修改、暂停或换方向。每章读完只做一个动作；如果当前处境不同，可以直接进入最像的一章。

这是给你自己的路线。家长、老师或朋友可以提供资源和安全支持，但不替你把兴趣变成成绩单，也不根据一次表现给你贴标签。

## 四章路线

1. [我不知道自己喜欢什么](01-not-sure-what-i-like.md)：从身边已经出现的好奇和不舒服开始，不急着命名天赋。
2. [先试一次，不必马上选择](02-try-without-choosing.md)：设计一个能停下来的小尝试，确认资源、时间和安全边界。
3. [试过却没坚持，接下来怎么办](03-when-you-did-not-keep-going.md)：分清活动不合适、方法太难、生活太满和暂时失去兴趣。
4. [比较体验，决定下一小步](04-compare-and-choose-next-step.md)：用自己的观察比较不同活动，把结论变成下一个可执行动作。

不想继续不等于失败。只要你能说明自己观察到了什么、想调整什么，这次尝试就留下了信息。

家长想了解支持方式，可另看[14–18 岁父母指导](../../../stages/家庭期（25-45岁）/育儿指导/14-18岁/_index.md)；那是另一种读者入口，不是本路线的前置课程。
