# 选择现在要读的内容

宝宝快出生了，孩子开始上学了，或者你想找一件自己愿意做的事——从眼前的问题进入就够了。

## 第一次当父母

[准备出生到三岁](parenting/new-parent/_index.md)是一条十五章的阅读路线。从家庭准备、医院里的第一天和回家后的照料，逐步读到孩子的动作、语言和自主。可以从头读，也可以从当前月龄进入。

正在发生呼吸、意识、出血或即时安全问题时，先看[安全与求助](../stages/家庭期（25-45岁）/育儿指导/quick-start.md#safety)。只需要换尿布、抱放或喂养的操作，直接查[护理目录](../stages/家庭期（25-45岁）/育儿指导/0-3岁/_index.md)。

## 孩子已经更大

进入[育儿阅读目录](../stages/家庭期（25-45岁）/育儿指导/_index.md)，选择孩子当前年龄。每个年龄目录同时提供默认阅读顺序和需要时再查的文章，读到下一篇不用再选择另一套路径。

眼前有作业、学习或兴趣选择的问题，也可直接看[问题查阅](learning/questions/_index.md)。

## 想探索自己的方向

[探索自己](exploration/youth/_index.md)面向正在想“我喜欢什么、要不要继续”的青少年。先做一次负担得起的尝试，再根据实际体验选择下一步。

已经知道要学什么，可以进入[兴趣课程](../interests/_index.md)，了解语言、登山或系统架构各自怎样开始。

## 父母自己的休息和关系

[父母支持](../stages/家庭期（25-45岁）/育儿指导/父母自身/_index.md)从睡眠不足、分工、压力和自己的生活讲起。你可以先处理最影响今天的那件事。

大学、工作、中年与老年的材料目前以概览为主，见[其他人生阶段](../stages/_index.md)。
