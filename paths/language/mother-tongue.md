# 母语发展路径

这是一条“先观察，再回应”的路径。语言不是每天完成多少词的任务，而是孩子在真实关系里逐渐学会理解别人、表达自己、讲述经历和读写思考的过程。年龄只帮助你找例子，不能替代对孩子变化的观察。

## 先从孩子现在的方式开始

选择最接近当前情况的一项：

- 还不会说词，但会看人、发声、伸手、递物或用哭声表达：先看[0–3 岁母语发展](../../interests/language/母语发展/0-3岁.md)的“来回互动”部分。
- 会说短句，正在讲故事、玩假装游戏或问很多“为什么”：看[3–6 岁母语发展](../../interests/language/母语发展/3-6岁.md)。
- 能独立阅读或写一小段话，但需要更清楚地理解文本、组织观点：看[6–12 岁母语发展](../../interests/language/母语发展/学龄期（6-12岁）.md)。

读完只选一个日常场景试用。孩子没有回应时，降低难度、换时间，或先满足休息和身体需要；不要把互动做成测试。

## 一条简单的互动循环

1. **看孩子在关注什么。** 他正在看、听、摸什么？他的身体是放松、兴奋，还是已经累了？
2. **用一句话接住。** 描述当下，或回应他的声音、动作和意图。
3. **停下来等。** 给他用眼神、手势、声音或词语接回来的机会。
4. **只增加一点。** 孩子说“车”，可以说“红色的车”；孩子指向门，可以说“要出门吗？”

这套循环能用在换衣、吃饭、散步、收拾、共读和游戏里。成人不必一直说话，回应孩子正在做的事比连续提问更有用。

## 不同年龄，观察什么

| 大致阶段 | 可以留意 | 成人可以做 |
| --- | --- | --- |
| 0–3 岁 | 对人声和脸的反应、发声和手势、理解熟悉词语、词语组合 | 模仿后等待；跟着孩子的关注命名；用自然语言描述照料和游戏 |
| 3–6 岁 | 句子变长、能按顺序讲一件事、理解别人的观点、对故事和文字感兴趣 | 少问“考题”，多让孩子讲；共读时讨论人物想法；把新词放回生活 |
| 6–12 岁 | 是否抓住文本主旨、区分事实与观点、能用证据说明想法、能修改文字 | 先听孩子的解释，再追问依据；允许先口述再写；一起比较不同表达 |

这些是选择互动方式的线索，不是达标表。已经出现的沟通能力倒退、对声音反应很少、长期没有进展，或沟通困难影响日常生活时，带上具体观察咨询儿科、听力或言语语言专业人员。双语、方言和多语环境应把所有语言中的理解、手势、声音和词语一起看。

## 把语言放进一天

今天只挑一个场景：

- **吃饭：** 说出食物和孩子正在做的动作，不要求跟读。
- **散步：** 跟着孩子看向的车、树或人，先说一个词，再停下来。
- **共读：** 可以只看一页、重复一句或讲图片；孩子离开时就结束。
- **收拾：** 用简单顺序描述“先放书，再关灯”，让动作和语言对上。

家庭中使用中文、方言或其他语言都可以。稳定、自然、能互相回应的交流，比追求固定输入比例更重要。故事机和屏幕可以作为共同活动的材料，但不能替代成人根据孩子状态做出的回应。

## 一个四周观察法

如果希望更有连续性，固定一个场景即可：

1. 第一周记录孩子如何发起或回应，不记录词语总数。
2. 第二周练习“观察—等待—回应”，每天只在这一个场景里做。
3. 第三周把孩子的兴趣扩展成一个词、一句话或一个动作。
4. 第四周回看：什么时刻最容易形成来回？孩子是否出现新的理解、手势、声音或表达？还有什么问题需要带给专业人员？

不要为了完成四周而强行继续。孩子的睡眠、饥饿、疾病和家庭语言环境都需要放在判断里。

## 与英语学习的关系

家庭最自然的语言应继续承担真实交流。第二语言可以围绕兴趣、学校或工作需要加入，不需要先把母语“学完”，也不用因双语而停止家庭语言。准备开始英语学习时，按当前听读和表达能力进入[英语学习路径](english.md)，不要只按年龄或词数升级。
