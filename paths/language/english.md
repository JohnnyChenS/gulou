# 英语学习路径

先找一个“能做但还不稳”的任务，再决定从哪里开始。年龄、词汇量和考试分数可以帮助选材料，却不能单独证明学习者已经进入下一阶段。

## 选择起点

| 如果你现在能…… | 从这里开始 |
| --- | --- |
| 只能认出少量词，听不懂简单指令或读不出短词 | [英语入门](../../interests/language/英语学习/beginner.md) |
| 能处理简单故事和熟悉对话，想读更长材料、写段落或参与讨论 | [英语进阶](../../interests/language/英语学习/intermediate.md) |
| 能独立读一般材料、说明观点并根据反馈修改表达 | [英语高阶](../../interests/language/英语学习/advanced.md) |

做一个小测试：拿一段没有提前练过的材料，先说出大意，再说明哪里不懂。材料几乎全懂，就提高一点难度；每句都要翻译，就降低难度。学习者可以在不同能力上处于不同阶段，不必整页升级。

## 学习循环

1. **理解：** 选大部分能懂的短材料，先抓主旨，不急着查每个词。
2. **注意：** 只查影响理解或反复出现的词句，把它放回原句。
3. **使用：** 用口头或文字复述、回答一个真实问题，哪怕只有几句。
4. **回看：** 记录哪一步卡住，下一次换材料、降低难度，或补一个具体基础。

听、读、说、写不必每天平均分配。当前要完成英文邮件，就围绕邮件练习；准备读小说，就把时间放在可理解的章节阅读和复述上。

## 三个阶段的重点

### 入门：让声音、文字和意思连起来

从常见短句、字母与声音、简单故事开始。目标是能在熟悉场景中听出或说出意思，并能借助拼读或词典处理短材料。家长陪伴时，用一句英语描述正在做的事即可，不要求孩子背诵一整套词表。见[英语入门](../../interests/language/英语学习/beginner.md)。

### 进阶：从理解到表达

用分级读物、短播客或感兴趣的文章扩大输入，练习复述主旨、说明观点、写一段文字和回应追问。遇到长材料时先分段，不要求每句话都译成中文。见[英语进阶](../../interests/language/英语学习/intermediate.md)。

### 高阶：让英语服务真实工作

选择专业、学术或公共表达中的真实任务：读一篇论文、写一封正式邮件、做一次汇报，分析作者的主张、依据和不确定处，再按反馈修改。高阶没有统一终点，专业方向决定词汇、语域和材料。见[英语高阶](../../interests/language/英语学习/advanced.md)。

## 家庭练习的最低版本

没有充足时间时，保留一个动作就够：选一段可理解的材料，听或读一遍，说出大意，再用一句英语回应。孩子抗拒或材料过难时，停下、换题材或回到较简单的输入；练习不是必须完成的日历。

不要把屏幕、应用或 AI 对话当作自动产生学习的设备。工具可以提供材料、反馈和对话机会，学习者仍需理解内容、尝试表达并核对错误。涉及儿童的平台应先确认年龄规则、隐私和成人陪伴条件。
