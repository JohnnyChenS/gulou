# 0-3 岁新手父母 Agent 周计划模板

## 使用场景

当用户输入宝宝月龄、当前观察、主要困扰和近期目标后，Agent 使用本模板生成 4 周计划。模板目标不是替代医生诊断，而是把父母的零散观察转化为阶段判断、低焦虑解释和可执行行动。

## 输入字段

| 字段 | 示例 |
|------|------|
| 宝宝月龄 | 2 个月 |
| 使用者角色 | 妈妈 / 爸爸 / 主要照料者 |
| 当前困扰 | 放下就醒、夜醒频繁、担心不会抬头 |
| 本周观察 | 每次只能睡 40 分钟；趴着 1 分钟就哭；喂后吐奶 |
| 父母状态 | 连续睡眠不足 3 小时，情绪烦躁 |
| 近期目标 | 先让晚上稍微可控，白天练一点抬头 |
| 每天可投入时间 | 5-15 分钟 |

## 输出结构

### 1. 当前阶段判断

说明宝宝大致处于哪个发展阶段，并明确哪些表现属于常见现象。

示例：

> 2 个月宝宝仍处于睡眠节律建立期，短睡、放下就醒、昼夜不稳定都很常见。当前优先级不是训练自主入睡，而是保护安全睡眠、识别清醒窗口，并让父母获得最低限度休息。

### 2. 本阶段核心成长任务

最多列 3 个，不做大而全规划。

- 建立安全睡眠和昼夜节律
- 掌握哭闹排查、抱娃、喂养、拍嗝、换尿布等基础照护流程
- 增加短时俯卧，支持抬头和颈背力量
- 保护父母基础睡眠，降低情绪消耗

### 3. 未来 4 周目标

| 周次 | 目标 | 完成标准 |
|------|------|----------|
| 第 1 周 | 记录清醒窗口和睡眠信号 | 至少记录 4 天，每天 3 次睡前信号 |
| 第 2 周 | 固定夜间照护流程 | 夜间按“换尿布 -> 喂奶 -> 拍嗝 -> 低刺激哄睡”执行 |
| 第 3 周 | 增加俯卧时间 | 每天累计 5-10 分钟，分多次完成 |
| 第 4 周 | 复盘睡眠和动作变化 | 总结最长连续睡眠、俯卧耐受和父母休息情况 |

### 4. 本周最重要的 1 个行动

只给一个主行动，降低执行阻力。

> 从宝宝睁眼开始计时，45-90 分钟内观察睡眠信号。不要等大哭再哄睡。

### 5. 每周观察指标

- 宝宝每天总睡眠时长
- 夜间最长连续睡眠时长
- 每天湿尿布数量
- 喂后吐奶或胀气次数
- 每天累计俯卧时间
- 父母最长连续睡眠时长
- 父母焦虑评分，1-5 分

### 6. 不用焦虑的正常现象

- 新生儿短睡、落地醒很常见
- 3 个月前昼夜节律不稳定很常见
- 喂后少量溢奶、偶尔拍不出嗝很常见
- 刚开始趴着抗拒很常见
- 父母在睡眠不足时情绪波动很常见

### 7. 需要警惕的信号

- 3 个月以下体温 >= 38°C
- 睡觉时嘴唇或指甲发青
- 呼吸停顿超过 20 秒
- 体重增长不良
- 父母有伤害自己或宝宝的想法

### 8. 下次复盘问题

- 这周宝宝最长连续睡眠有多久？
- 哪个睡眠信号最容易观察到？
- 每天湿尿布数量是否稳定？
- 喂后拍嗝和竖抱是否减少不适？
- 每天累计趴了多久？
- 父母是否至少有一次连续 4 小时睡眠？
- 本周最焦虑的问题有没有变化？
