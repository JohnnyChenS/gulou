# 0–3 岁新手父母 Agent 周计划模板

这是公开的输出结构示例，供理解知识怎样用于计划；不是已经上线的个体建议，也不规定私有产品的具体行为。父母阅读知识，应先进入[连续阅读主线](../parenting/new-parent/_index.md)。

## 使用前先判断安全与信息是否足够

出现呼吸困难、发蓝灰、难以唤醒、抽搐或成人无法保证自己和孩子安全，先立即求助，不生成练习计划。低月龄发热、摄入明显变差等需要及时医疗评估，不能用四周观察替代。具体联系条件见[安全与求助](../../stages/家庭期（25-45岁）/育儿指导/quick-start.md#safety)。没有描述危险信号，不等于已经排除了危险。

计划只适合可以在家庭支持下观察和调整的事情。早产、疾病、特殊喂养方案或持续担忧，应先确认适用条件和专业安排。不要从月龄自动推出每天必须做什么。

## 输入要让下一步有依据

| 输入 | 为什么需要 |
| --- | --- |
| 月龄、出生及健康情况 | 判断资料是否适用，是否已有个体方案 |
| 最近发生的具体变化 | 区分长期处境和新发异常，避免只凭“总哭”猜原因 |
| 喂养、排泄、睡眠及清醒时的状态 | 把相关观察放在一起，不用单一数字排除风险 |
| 当前照料者、可用支持和休息 | 选择真正可以执行的行动 |
| 本次希望解决的问题 | 控制计划范围，不自动展开百科全书 |

下面用“照料交接经常遗漏信息”说明九个输出部分；例子是编辑示范，不是通用于所有宝宝的方案。

## 1. 当前阶段判断

说明已知信息支持什么、还缺什么，以及需要先确认的安全和个体条件。例如：“你们正在磨合照料轮班；目前描述指向交接信息不完整，但宝宝健康与喂养是否正常仍需结合实际情况和随访判断。”不把阶段说明写成诊断。

## 2. 核心照料或成长任务

围绕这次问题选择少量关联任务：保持照料安全、说清最近发生了什么、让下一位照料者能接手。无需同时安排睡眠训练、动作练习和学习课程。

## 3. 四周目标

| 阶段 | 可以调整什么 | 怎样判断是否有帮助 |
| --- | --- | --- |
| 第一周 | 用一张简单交班卡说清当前状态与下一班责任 | 接手者能复述下一步和联系条件 |
| 第二周 | 删除无用记录，补足反复遗漏的信息 | 交接时少了哪些临时猜测 |
| 第三周 | 检查照料与休息是否实际有人负责 | 成人是否获得了可用的休息与支持 |
| 第四周 | 讨论保留什么、还需什么帮助 | 方法是否适合家庭，是否出现应提前处理的变化 |

周次是组织复盘的例子，不是疗效期限，也不保证宝宝更快睡整夜。出现健康变化或计划不适用时立即调整，不等第四周。

## 4. 本周主要行动

只选择一个可以执行的动作。例如：“交班时同时说明最近一次有效喂养、尿便和当前状态，再明确下一班是谁。接手者复述一遍。”不要规定所有宝宝统一的清醒窗口、喂养间隔或护理次序。

## 5. 观察指标

看这次行动相关的变化：交接遗漏在哪里，宝宝与成人的新变化是否有人知道，谁实际接手，以及什么情况需要联系专业人员。记录服务于交流，不要求把全天每个行为量化。

## 6. 常见现象及其条件

早期夜醒、哭闹或少量溢奶可能出现，但是否属于可以继续照料的情况，要结合呼吸、清醒、摄入、排泄及变化判断。不能把“常见”写成“肯定没事”，也不因单次表现判断家庭做得不好。

## 7. 红旗与求助

每份输出都应保留与当前问题相关的联系条件；发现即时危险时把行动提示提前，不藏在长计划之后。不要等呼吸异常达到某个秒数才求助，也不要用一个训练目标解释明显倒退或持续状态变差。

照料者有伤害自己或宝宝的想法、严重混乱或无法保证安全时，让可信任成人接手孩子并陪伴当事人，立即联系当地急救或危机服务。本文和计划都不能替代这些帮助。

## 8. 复盘问题

这次方法解决了哪个具体困难？哪项安排实际上没有发生？有没有新变化需要提前求助？下一步是保留、简化、换方法，还是找专业支持？

复盘不考核宝宝是否达到统一进度，也不要求父母获得某个固定长度的睡眠才算成功。

## 9. 来源与继续阅读

链接到实际使用的知识，并说明它支持哪部分判断和行动。护理细节可以查[操作目录](../../stages/家庭期（25-45岁）/育儿指导/0-3岁/日常护理/_index.md)，成人支持可查[父母自身](../../stages/家庭期（25-45岁）/育儿指导/父母自身/_index.md)。引用可达、格式完整或来自权威机构，不等于已经核对该计划适用于个人。
