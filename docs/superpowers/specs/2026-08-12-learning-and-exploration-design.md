# 学习与探索知识路径设计

**状态**：已确认设计，待实施计划

**日期**：2026-08-12

**适用仓库**：`gulou-core`

## 1. 背景

当前知识库已经有不少与学习相关的内容：0–3 岁的依恋、因果探索、共同注意、早期阅读和符号思维，3–6 岁的执行功能、专注和前阅读，6–9 岁的创造性思维与独立阅读，9–12 岁的创新思维，12–14 岁的学业压力与时间管理，以及面向学龄儿童至成人的循证学习方法。

这些内容分别放在认知与心理路径、脑健康路径和兴趣目录中。家长提出的实际问题却通常是连续的：孩子怎样保有好奇心，怎样形成学习习惯，进入学校后怎样学会知识，课外怎样发现并深入兴趣，怎样逐步学会管理自己的学习。当前缺少一条能把这些问题串起来的公开入口，也缺少部分年龄段的关键桥接内容。

3 岁前同样需要纳入，但目标不是把婴幼儿提前变成“学习者”。这一阶段的学习地基是安全感、回应性互动、共同注意、语言、游戏、因果体验和自由探索。新内容应帮助照护者理解这些行为的意义，并链接已有的婴幼儿文章，而不是添加识字、算术或坐定训练。

## 2. 目标

第一轮建立一条覆盖 0–18 岁的“学习与探索”导航主线：

1. 让家长能按孩子年龄找到当前最重要的学习与探索任务。
2. 把“学习习惯、好奇心、学校学习、兴趣拓展、学习能力”放在同一条发展连续线上。
3. 复用已有文章，只在明确缺口处新增内容，不复制执行功能、阅读、循证学习和学业压力的正文。
4. 把兴趣培养写成观察、试用、复盘和逐步深入的过程，不写成寻找“唯一天赋”或报班清单。
5. 区分正常差异、家庭可以尝试的支持、需要和学校协作的情况，以及需要专业评估的情况。
6. 让内容可供公开知识网站阅读，也能为后续 Agent 选择内容提供稳定入口；本轮不改变 Agent 配置。

## 3. 非目标

本轮不做以下工作：

- 不为每一种兴趣建立音乐、体育、艺术等完整课程；先建立通用的兴趣发现与拓展框架。
- 不提供统一的每日学习时长、固定注意力分钟数、保证提分的方法或“培养天才”的方案。
- 不把学习成绩、阅读量、兴趣数量或训练完成度当作孩子价值或潜力的代理指标。
- 不把学习困难、注意问题、拒学或情绪变化写成家庭可自行诊断的标签。
- 不一次性重写现有年龄路径、阅读文章、脑健康文章或学业压力文章；只做必要的局部互链和冲突修正。
- 不向 `gulou-agent` 的知识清单添加内容，也不新增 `agent_use` 元数据。

## 4. 核心设计原则

### 4.1 先有安全和探索，再谈方法

0–3 岁的文章先讲回应性照料、共同注意、语言和游戏；3–6 岁先讲游戏中的投入、提问、尝试和收尾；学龄后才逐步引入作业、检索、间隔、反馈和时间管理。不能把适合青少年的自我管理工具直接下压给幼儿，也不能把婴幼儿的游戏建议写成学科训练。

### 4.2 好奇心不是服从测试

好奇心通过孩子提出问题、持续观察、改变做法和愿意再次尝试来观察，而不是通过“问答答对了多少”来衡量。成人的任务是提供安全材料、留出时间、追问思路并帮助核验，不是把每次探索都改造成考核。

### 4.3 学习能力必须落到具体任务

文章应区分知识、策略、执行和迁移：能背出一个概念不等于能在新情境使用；完成练习不等于形成通用智力；看起来专注也不等于所有任务都能持续。涉及检索、间隔、反馈和 AI 时，复用 `paths/brain-health/evidence-based-learning.md` 的证据边界，不另造“万能方法”。

### 4.4 兴趣要允许试错和退出

兴趣路径采用“观察线索 → 低成本试用 → 看过程反应 → 复盘是否继续 → 逐步深入”的循环。孩子可以暂时喜欢、转向、暂停或放弃；家长不应把一次报名、一次比赛或一项成绩解释为长期方向。

### 4.5 使用自然、具体、可核验的中文

正文使用 `humanizer-zh` 的编辑原则：少用口号、夸张比喻和连续排比，优先写具体场景、可观察行为和下一步动作；不伪造个人经历，不用“科学证明一切”式归因。证据不确定时明确说明范围、条件和限制，不能为了安慰家长而过度保证。

## 5. 信息架构

### 5.1 新增文件

#### `paths/learning/_index.md`

新增“学习与探索”总入口，负责：

- 解释 0–18 岁学习发展的连续逻辑；
- 提供 0–3、3–6、6–9、9–12、12–14、14–18 六个年龄段的入口；
- 说明学习习惯、好奇探索、学校学习、兴趣拓展和学习能力之间的关系；
- 链接现有认知与心理路径、脑健康学习方法和新补充的年龄文章；
- 明确“当前阶段只选一个小动作”的阅读和执行顺序。

### 5.2 必要的现有文件调整

## 6. 年龄递进与文章边界

| 年龄 | 家长真正要解决的问题 | 文章应给出的可观察信号 | 不应承诺的结果 |
|---|---|---|---|
| 0–3 | 孩子是否在安全关系中有机会观察、互动、尝试和表达 | 是否主动发起/回应互动，是否重复探索，是否在支持后回到游戏或交流 | 不承诺超前识字、数学或固定智力提升 |
| 3–6 | 如何让孩子愿意投入一件事并从失败中再试一次 | 是否会提问、换方法、完成小闭环、参与共读和生活任务 | 不承诺坐得越久越聪明，不把自由游戏变成作业 |
| 6–9 | 如何从家庭照料过渡到学校中的稳定学习常规 | 是否能开始任务、说出不懂之处、根据反馈修改、逐步积累基础知识 | 不承诺某种作息或奖励制度必然提分 |
| 9–12 | 如何学会组织知识并知道自己哪里没学会 | 是否能用自己的话解释、检索后核对、记录错误、完成小项目 | 不承诺“成长型思维”或单一方法解决所有科目问题 |
| 12–14 | 如何从被安排逐步转向自我监控 | 是否能设定小目标、估计用时、根据结果调整策略、辨别可靠信息 | 不把拖延、偏科或成绩波动简单归因于态度 |
| 14–18 | 如何承担学习管理并探索更深的方向 | 是否能独立制定计划、寻求反馈、完成长期项目并复盘选择 | 不把考试成绩等同于能力、价值或唯一人生路径 |

## 7. 文章统一结构

新增年龄文章和兴趣指南使用以下结构，允许根据主题合并短节，但不得缺少核心信息：

1. 一段具体的家长场景，先承认问题的真实难度，不制造危机感；
2. 这个年龄段正在发展的任务，以及正常差异的范围；
3. “可以先观察什么”，把抽象目标转成可见行为；
4. 两到四个低成本行动，说明做法、适用条件和何时停止加码；
5. 家庭与学校如何分工，何时需要和老师或专业人员沟通；
6. 常见误区与证据边界；
7. 需要关注的信号，明确“不用于自我诊断”；
8. 今天能做的一件小事；
9. 相关路径、已有文章和主要来源。

文章 frontmatter 按现有阶段文章规范填写 `id`、`stage`、`track`、`domain`、`topic`、`age_range`、`difficulty`、`review_status`、`references`、`tags` 和 `related_prompts`。新文保持 `review_status: draft`，直到完成人工内容和专业安全审阅。

| 新主线 | 优先复用的现有内容 |
|---|---|
| 0–3 学习地基 | 安全依恋、因果关系推理、联合注意、早期阅读探索、符号思维、自主意志 |
| 3–6 好奇与学习准备 | 执行功能、学龄前专注力、早期阅读习惯、前阅读与前数学、情绪调节 |
| 6–9 学校学习习惯 | 从亲子阅读到独立阅读、创造性思维、口头表达、循证学习方法、睡眠与运动 |
| 9–12 自我调节学习 | 创新思维、历史与世界观、公众表达、循证学习方法、信息素养相关内容 |
| 12–14 元认知与策略 | 学业压力与时间管理、青春期沟通、数字素养、循证学习方法 |

## 9. 安全与证据边界

- 不把年龄表写成截止日期，不用单次表现判断能力或潜力。
- 对学习策略使用“在具体任务中可能更可靠”这类校准语言，不把练习收益外推成通用智力或必然提分。
- 对兴趣发展强调自主性、可逆性和家庭资源边界，不鼓励高压投入或用金钱奖励替代兴趣。
- 对持续影响学校、家庭或社交功能的阅读、注意、学习、情绪或拒学问题，建议与老师、儿科、发育行为或心理健康专业人员沟通；急性安全风险沿用现有危机和急救提示。
- 涉及屏幕、AI、睡眠、营养和心理健康的内容，链接现有安全指南，不为新文章另造医疗结论。

## 10. 验收标准

实施完成后必须满足：

1. `paths/learning/_index.md` 能从 `paths/_index.md` 进入，并覆盖 0–18 岁六个年龄段和跨年龄兴趣指南。
2. 0–3 岁文章明确“探索地基”而非提前学科训练，并链接至少四篇已有婴幼儿认知文章。
3. 3–18 岁每个年龄段都有明确的学习/探索任务、可观察信号、低成本行动和边界说明。
4. 兴趣指南包含发现、试用、复盘、深入和退出机制，并链接现有兴趣目录。
5. 新文章没有保证提分、提高智商、错过关键期即无法补救或“每个孩子都应如此”的表述。
6. 所有内部链接、frontmatter、标题层级和中文文件路径通过检查；网站构建通过。
7. `gulou-agent`、当前 MVP 知识清单和生成目录没有被手工修改。

## 11. 后续实施顺序

规格确认后，先制定实施计划，再按以下顺序执行：

1. 创建学习与探索总入口和兴趣发现指南的骨架；
2. 依次补写 0–3、3–6、6–9、9–12、12–14、14–18 六篇年龄文章；
3. 更新阶段路径、年龄索引和兴趣索引的链接；
4. 运行链接、frontmatter、禁用表述和网站构建检查；
5. 进行一次独立内容/安全复核，再提交正文变更。
