# 脑健康阶段反向导航与访谈审计移除设计

**状态**：用户已确认设计

**日期**：2026-07-22

**适用仓库**：`gulou-core`

## 1. 目标

本次修订解决两个信息架构问题：

1. 终身脑健康路径能指向年龄阶段，但年龄阶段入口不能反向发现脑健康内容。
2. 两期访谈包含较多错误、夸大或证据不足的说法，不应作为公开参考资料或脑健康正文的阅读入口。

完成后，读者从任一主要年龄入口都能看到适龄的脑健康与学习摘要；公开内容直接呈现现代指南和研究支持的结论，不再围绕访谈组织叙事。

- 已删除远端实施分支。

## 3. 删除访谈审计

删除：

- `references/brain-science-interview-audit-2026.md`

移除以下入口中的审计链接或条目：

- `references/_index.md`
- `paths/brain-health/_index.md`
- `paths/brain-health/evidence-based-learning.md`

保留 `references/brain-health-evidence-framework.md`。它是通用的证据编辑规范，不为任何具体访谈背书；其中“访谈、新闻或社交媒体只能作为待核查线索”的一般规则可以保留。

`paths/brain-health/` 下的正文不得提及两期访谈、受访者或视频核查过程。正文只陈述可追溯到权威指南、系统综述或直接研究的知识与行动边界。

## 4. 阶段摘要卡片

在 13 个年龄主入口增加统一标题 `## 脑健康与学习`。每个卡片包含：

- 该阶段最重要的脑健康或学习任务；
- 一条边界说明，避免把正常差异写成衰退或承诺提分、智力提升、疾病预防；
- 1–3 个适龄链接。

卡片只做导航和摘要，不复制专题正文。

### 4.1 顶层人生阶段入口（7 个）

| 阶段 | 适龄摘要重点 | 目标链接 |
|---|---|---|
| 青春期（14–18） | 睡眠、运动、情绪与关系、自主学习；控制系统仍在发展但不等于“不理性” | 0–18 指南、循证学习、终身总纲 |
| 大学期（18–22） | 睡眠与心理健康、自主学习、检索与反馈、AI 辅助学习边界 | 循证学习、终身总纲 |
| 职场开始（22–28） | 久坐与睡眠、压力、持续学习和技能迁移 | 循证学习、终身总纲 |
| 职场发展（28–40） | 心血管与代谢基础、压力恢复、持续学习；不采用“30 岁整体衰退”叙事 | 循证学习、终身总纲 |
| 家庭期（25–45） | 成人自身脑健康与育儿阶段支持；照料者睡眠和压力同样重要 | 终身总纲、0–18 指南、循证学习 |
| 中年期（40–60） | 血压血糖血脂、运动、睡眠、听视力、持续学习；强调风险降低而非保证预防 | 终身总纲、循证学习 |
| 老年期（60+） | 正常变化、功能维持、多领域风险管理、补偿和就医红旗 | 60+ 专题、终身总纲 |

### 4.2 育儿年龄入口（6 个）

| 阶段 | 适龄摘要重点 | 目标链接 |
|---|---|---|
| 0–3 | 安全、回应性照料、语言互动、自由活动和睡眠；不做“开发率”训练 | 0–18 指南、终身总纲 |
| 3–6 | 游戏、共同调节、基本动作、语言和早期数概念；不提前学科加速 | 0–18 指南、终身总纲 |
| 6–9 | 睡眠、运动、阅读、检索和反馈；不保证技巧提分 | 0–18 指南、循证学习 |
| 9–12 | 自我调节学习、同伴关系、屏幕习惯和知识结构 | 0–18 指南、循证学习 |
| 12–14 | 青春期睡眠变化、情绪与社会敏感性、自主性和学习策略 | 0–18 指南、循证学习 |
| 14–18 | 心理健康、关系、自主性、学业压力、数字生活和 AI 使用边界 | 0–18 指南、循证学习 |

不修改：

- `育儿指导/0-3岁/日常护理/_index.md`
- `育儿指导/父母自身/_index.md`

这些页面不是年龄主入口，添加相同卡片会造成导航重复。

## 5. 链接规则

- 顶层阶段入口使用 `../../paths/brain-health/...`。
- 育儿年龄入口使用 `../../../../paths/brain-health/...`。
- 老年期继续保留本地 `认知保持/brain-health-01.md` 链接，同时增加终身总纲入口。
- 不从阶段入口链接 `references/`，公开阅读路径只指向面向读者的知识正文。
