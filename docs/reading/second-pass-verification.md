## 用户目标与编辑决定

读者需要能沿一条路专注理解，又能在遇到具体问题时查资料。文字需要把概念、例子和下一步接起来，减少空泛解释、重复建议和未经支持的确定结论。

本轮采用用户明确提出的原则：可以全面改写、合并或删除旧内容，不承担旧 URL、标题、锚点和入口的兼容要求。更新当前站内引用即可。现有专题只有具备独立用途才继续存在，不能以“保留原内容”为理由再加一个入口。

主要风险是删改后跳转失效、章节顺序与正文不一致，以及编辑压缩使求助条件或安全例外丢失。验收对应检查当前链接和锚点、实际章节前后关系、来源与审核状态，并走读新手父母、年龄主线和本人探索。

## 正文改写的具体变化

| 原来的问题 | 现在怎样组织 |

| 护理专题重复前后摘要、当天动作和每周复盘 | 按信号、操作、观察和求助组织；睡眠安全前置，喂养信号与喂后照料重新排序 |
