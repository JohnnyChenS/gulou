# 父母支持与兴趣整合独立复核

复核日期：2026-10-05

复核范围：`worker-parents-interests.json` 所列父母支持目录与四篇重点文章；语言总入口、英语路径及 beginner/intermediate/advanced 三篇正文；登山总入口及三个阶段正文；系统架构既有课程入口与课程契约。本文只记录会影响线性理解、误判/延误风险或安全分支的实质问题，不做一般文风润色。

## 结论

这轮父母支持整合的基本方向是对的：`paths/parenting/parent-wellbeing.md` 和父母目录都明确照料者专题不是儿童年龄进度，四篇短路线也有返回新手父母主线的说明。产后抑郁文章把危机、持续困扰和普通波动分开，睡眠文章把“今晚先安全交接”放在前面；夫妻调适文章也明确威胁、暴力和安全风险优先。`worker-parents-interests.json` 对这些文件的 `rewritten`/`integrated` 状态总体诚实，且父母文章的 `sources_checked: []` 没有假称本轮完成医学文献核验。

语言和登山入口也已经从年龄通关转向能力或风险场景，登山总入口尤其清楚地写出年龄不决定技能等级、网页不能替代现场带训和救援。系统架构课程保留是合理的：`interests/_index.md` 已把它限定为面向有多年开发经验工程师的独立兴趣路线，系统架构总入口、十阶段 `route_order` 和各阶段 `route_next` 也确实存在。

仍有以下问题值得在合并前处理。

## 可操作问题

### 1. [P1] 父母短路线没有按“尚未出生/已经出生”分叉

位置：`stages/家庭期（25-45岁）/育儿指导/父母自身/_index.md:22-31`；`paths/parenting/parent-wellbeing.md:19-31`

目录要求新手按“产前准备 → 产后调适 → 睡眠剥夺 → 产后抑郁”顺序读四篇。一个已经出院、正在被夜醒和疲劳困住的新手父母从这里进入，会先被送回“产前准备”；专题路径虽有阶段表，却没有明确告诉出生后的读者从第二篇或当前问题直接开始。这样会让主线入口和实际情境错位，也可能让读者在最需要睡眠安全时先读一篇已经过时的准备清单。

建议在短路线第一屏加条件分支：孕期从产前准备开始，宝宝已经出生则从“新手父母心理调适”或“今晚无法安全交接”开始；两者都保留危机优先提示和读完返回当前儿童主线的动作。

### 2. [P1] 危机优先级仍主要藏在文章内部，目录入口不够显眼

位置：`paths/parenting/parent-wellbeing.md:13-17,38-40`；`stages/家庭期（25-45岁）/育儿指导/父母自身/_index.md:24-31,86-90`

父母路径的说明是“遇到哪个问题就先读哪一项”，短路线则从准备开始。虽然产后抑郁和睡眠文章开头都有立即求助段落，目录本身没有在短路线之前给出一句清晰的“若有自伤/伤害宝宝、幻觉、严重混乱或无法保持安全，跳过路线立即让另一位成人接手并求助”。疲惫或焦虑中的读者可能把“按顺序阅读”误解成先完成前文再判断危机。

建议把危机分流作为父母目录和专题路径的第一屏固定块，并把普通路线明确标为“没有立即危险时使用”。这不是新增医学内容，而是把现有文章已经写出的安全分支前置。

### 3. [P2] 父母目录与专题路径重复提供两套目录，削弱唯一入口

位置：`stages/家庭期（25-45岁）/育儿指导/父母自身/_index.md:35-84`；`paths/parenting/parent-wellbeing.md:19-36`

父母自身目录已有四篇短路线、四篇早期主题和十篇后续主题的表格；专题路径又提供一张覆盖大部分相同文章的阶段表。两页都说读完回到儿童主线，但新手从网站不同位置进入后会看到不同的分类逻辑：一页按“短路线/后续年龄段”，另一页按“孕晚期/0–12个月/0–18岁”。这会重新产生需要自己判断“该从哪张表开始”的蜘蛛网。

建议指定一个 canonical 入口：父母目录只保留危机块、四篇短路线和一个按问题查找表；专题路径只保留一句用途说明和指向该目录的链接，或反过来由专题路径承载唯一表格。不要同时保留两套完整文章目录。

### 4. [P2] 产后抑郁的目录年龄标签可能造成不必要的截止感

位置：`paths/parenting/parent-wellbeing.md:26` 的 `0–24 个月`；`stages/家庭期（25-45岁）/育儿指导/父母自身/_index.md:65-67` 的 `孕期-12月`；文章本身 `postpartum-depression-01.md:81,88-91`

正文已经写明：当事人不是分娩者，或宝宝已经出生几个月，都不能据此排除求助；并且“约两周”不是等待期限。可是目录仍给出 `孕期-12月` 与 `0–24个月` 的阶段框，容易让新手把它理解成超过这个时间就不属于本页。NIMH 将围产期抑郁定义为孕期及产后数周、数月的情况，并明确症状应交由专业人员判断；CDC 的产妇警示页面也覆盖分娩后一年内的紧急信号。

建议目录改为“孕期及产后，出现相关症状时按需阅读”，把月份保留为导航背景而不是适用截止点。文章的两周提示可以保留，但目录和睡眠文章都应继续显式写“不等到两周才求助”。

### 5. [P1] 夫妻调适中的“不要纠正”缺少婴儿安全例外

位置：`stages/家庭期（25-45岁）/育儿指导/父母自身/关系维护/couple-adjustment-01.md:117-121`

“让他用自己的方式带孩子（不要纠正‘你做得不对’）”有助于避免把共同养育写成监督，但在新手父母页面中没有限定“非安全细节”。读者可能把这句话套用到安全睡眠、抱持、喂养、用药或已经明确的医疗交接上，从而把关系建议误读成不要及时纠正危险做法。

建议改成：生活偏好和非安全细节可以允许对方形成自己的做法；涉及安全睡眠、喂养、药物、抱持和专业医嘱时，以共同确认的安全规则为先，发现风险应立即暂停并纠正。这样保留“共同养育”目标，也不让关系修复建议覆盖儿童安全边界。

### 6. [P2] 母语路线仍用固定频次和年龄词汇量作显眼的行动标准

位置：`paths/language/mother-tongue.md:15-20,29-35,61-65`

路径开头说“不是按年龄打卡”，但同一页仍把 `12–18 月：50 个词`、`18–24 月：200–300 词` 和“每天 3 次 × 2/5 分钟”“每天 1 次 × 10 分钟”放在主表中。对零背景家长来说，这些数字会比“观察理解、表达和互动变化”的说明更像达标线，也与入口不把年龄和固定分钟数当标准的设计冲突。这里没有把数字标成单纯示例，且没有紧邻的“不用于筛查或诊断”提示。

建议主路径只保留可观察的互动和沟通信号；若要保留频次，把它移到“可选示例节奏”并明确可以随孩子状态、家庭语言环境和照料负担调整。词汇量不要在总入口承担筛查功能，担忧时链接到专业评估边界。

### 7. [P1] 英语路线虽有免责声明，实际仍把日历和数字自检做成隐性毕业门槛

位置：`paths/language/english.md:28-68`；`interests/language/英语学习/beginner.md:36-67,367-368`；`interests/language/英语学习/intermediate.md:79-87,276-280`；`interests/language/英语学习/advanced.md:82-100,221-286`

入口说日历只是可删减顺序，但路线表仍写成“30 周/20 周/12 周”并列出 `200–300 词`、`1000–1200 词`、`100 词/分钟`、`3 分钟自我介绍`、`200 词摘要`等阶段标准。三篇正文还分别出现“毕业标准”、固定周次和逐日任务。新手会同时看到“不要按日历毕业”和“第30周毕业标准”，很难判断哪些是理解信号、哪些只是示例。

建议把路线表改为“先做哪类任务、用什么观察信号决定继续/退回”；把完整日历收进可选附件或折叠区，并在标题和表格中统一标为示例。对固定词数、语速和分钟数，除非确有明确测量目的，否则改为“能否理解、复述、互动和修订表达”。

### 8. [P1] 英语中级把未成年人外部交流平台列为升级步骤，却没有安全前置

位置：`interests/language/英语学习/intermediate.md:111-119`

口语练习把 AI、同伴、`HelloTalk` 和 `italki 青少年专区`排成四级路径，但没有说明平台年龄资格、家长/监护人参与、隐私保护、陌生人交流边界或如何处理不当内容。该文件的 `age_range: 10y+` 覆盖未成年人，因此这不是一般资源偏好，而是实际安全分支缺失。

建议在任何外部平台链接前增加未成年人使用条件：先采用家长可见的本地或受监督练习；核对平台当前年龄和地区规则；不公开真实姓名、位置、学校、联系方式或家庭经历；出现不适立即退出并告诉可信任成人。没有这些条件时，外部平台不应被表达为“第三级”。

### 9. [P1] 登山 Prompt 排在安全边界之前，并要求 AI 生成技术操作步骤

位置：`interests/mountaineering/beginner.md:36-75`；`interests/mountaineering/intermediate.md:34-56`；`interests/mountaineering/advanced.md:35-57`

三个阶段都有清晰的进入条件和安全边界，但读者首先看到的是“复制给 AI 获得完整指导”。进阶 Prompt 要求“技术描述需配具体操作步骤”，涉及绳索保护、下降、冰雪和裂缝救援；高阶 Prompt 还直接询问高海拔、冰川救援和冻伤/高原病处置。页面后面的安全边界又说这些必须现场训练、不能依靠网络文章。对线性阅读者而言，顺序和 Prompt 语气会削弱后面的限制。入门 Prompt 的“让我感到登山不是极限运动，我可以做到”也可能在路线、天气和健康条件未核对前产生过度保证。

建议先展示安全边界和“AI 只能帮助准备问题、检查清单和决策证据，不能批准路线或替代现场教学”，再把 Prompt 放到可选区。进阶/高阶 Prompt 应改为向教练、向导、医生和当地管理方列出待核实问题与撤退条件，避免让模型提供可脱离现场训练执行的绳索、救援或医疗步骤。

### 10. [P1] 系统架构主干、纵向切片和综合项目的先后关系相互冲突

位置：`interests/system-architecture/_index.md:52-66,81-87`；`interests/system-architecture/capstone/_index.md:14-40`

系统架构总入口明确主干是 `00 → 09`，并说明纵向切片“不改变主干顺序”；但同一页又写“先完成日志、状态与恢复纵向切片综合评审……完成十个阶段后进入综合项目入口”。综合项目页则写明自己位于阶段 `0–9` 之后，且六个正式单元要在最终评审前交付。新学习者无法判断：纵向切片是主干中的可选支路、应在相关阶段读完后完成，还是十阶段之前的先修；`Page Cache → WAL → Replicated Log` 的六单元顺序也跨越主干阶段。

建议只选一种清晰契约：默认按 `00→09` 主干阅读，纵向切片标为完成 `01/03/04/05/06` 后的可选复盘，综合项目统一放到 `09` 之后；或者把纵向切片明确声明为另一条独立路线，并写出开始条件、返回点和终点。当前“先完成”应删除或改成条件式说明。

### 11. [P2] 系统架构仍有固定总时长，和“按选定路线完成”的定义未完全对齐

位置：`interests/system-architecture/_index.md:75-87`

课程 frontmatter 和正文同时写“12个月、每周6–8小时、48个内容周和4个缓冲周”，而完成定义又说是“走完选定路线”，并允许阶段内材料随验证结果调整。对有多年经验的工程师，这会被理解为课程设计预算而非医学或儿童安全问题，但它仍给新学习者制造统一进度期待，也和系统架构本身强调证据、实验和返工的路线契约不完全一致。

建议把它改为“示例投入预算”，明确不作为完成期限、能力证明或阶段门槛；真实耗时以实验、复盘和产物质量为准。

## 父母文章的正文整合仍不均匀

以下文章虽然在 worker 记录中标为 `rewritten`，但抽查显示有些仍主要是加了入口、删了数字或换了提醒语，正文核心判断没有达到“给出具体支持而不是泛化安慰”的要求，建议列入下一轮实质重编：

- `育儿压力/comparison-anxiety-01.md:28,36-40,67,77`：把社交比较说成在社交媒体时代“无限放大”，用“没有人会发……”和“你不知道他们私下怎么吵架”代替可执行的信息判断；更严重的是“吃多吃少是气质差异，不是能力差异”可能让家长忽略喂养、体重、吞咽或疾病背景。应改成比较信息的有限性、哪些观察可回到儿童主线、哪些喂养担忧需要专业评估，并把“取关”变成可选择的实验而不是“不需要犹豫”的训诫。
- `育儿压力/parenting-anxiety-01.md:46-52,66-67,141-144`：绿/黄/红三档把“正常担忧、不需要干预”和“建议正念/运动”写得过于像筛查和处方；胸闷、呼吸困难、功能下降以及伤害想法需要更清楚地分开紧急安全、尽快评估和可先尝试的支持。正文已有“不作诊断”的声明，但表格仍可能把有风险的情况压成颜色。
- `关系维护/parenting-support-network-01.md:51-58`：具体求助示例是有用的，但“保持 2–3 个核心支持者就够了”和“线下比线上更有效”没有情境条件，既制造数量目标，也可能否定异地、线上或专业支持。应按“能否在需要时联系、能否完成具体交接、是否可靠安全”重写支持网络的判断。
- `自我照顾/identity-maintenance-01.md:32-37,53-58`：把身份单一化直接箭头连接到焦虑、夫妻紧张、抑郁风险和空巢危机，再用“照顾好自己是照顾好孩子的前提”作因果总结。应改为可能的体验信号和可撤销的小尝试，不能把恢复个人兴趣写成每个照料者的心理健康条件。
- `育儿压力/perfectionism-trap-01.md:64-76`：允许降低不涉及安全的家务标准是好的，但“一个错误不会毁掉孩子”“偶尔失误……微不足道”过于绝对，无法覆盖严重或重复的失误。应把安慰改为评估错误类型、立即修复、寻求交接/专业帮助以及长期互动模式；安全、虐待和持续失责应明确排除在“偶尔失误”之外。
- `parental-role-modeling-01.md:68-78`：表格中“说谎是可以的，只要不被发现”虽放在“孩子学到什么”一栏，仍可能被脱离表格误读为作者主张。应直接改成“孩子可能把它理解为……”，并保留成人承认、解释隐私/拒答边界和修复的具体示例。
