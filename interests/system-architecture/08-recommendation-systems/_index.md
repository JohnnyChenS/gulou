# Recommendation Systems

## 阶段目标

建立推荐从召回到实验反馈的在线闭环，并评审缓存、降级、容量和偏差。

## 核心单元

- Candidate Generation、Retrieval、Ranking、Re-ranking、Collaborative Filtering、Content-based Recommendation、Matrix Factorization、Embedding、ANN、Vector Search、Two-tower Model 与基础 CTR 预估。
- 多目标排序、冷启动、实时特征、在线推荐服务、缓存、降级、容量、A/B Testing、反馈回路与评估偏差。

## 组件映射

Candidate Generation、Retrieval、Ranking、Re-ranking、在线服务、缓存和实验相关组件。

## 综合项目演进

完成召回、排序、重排、在线服务和实验闭环。

## 阶段挑战

评审冷启动、实时特征、降级与 A/B Testing 反馈偏差对容量、正确性和成本的影响。

## 阅读顺序

以可服务的模型和特征链路为进入条件；完成推荐闭环挑战后进入 AI Engineering。
