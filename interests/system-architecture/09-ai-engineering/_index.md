# AI Engineering

## 阶段目标

在明确 Workflow 与 Agent 边界的前提下，构建有评估、安全、观测和成本控制的 AI 能力。

## 核心单元

- Token、Context Window、Structured Output、Embedding、Vector Search 与 RAG。
- Tool Calling、Workflow、State Machine、Agent Loop、Memory、Planning 与状态持久化。
- Evaluation、Guardrails、回归测试、Prompt Injection、权限、工具隔离、数据边界、Replay、Observability、模型升级与降级。
- 无限循环、工具失败、延迟、Token 成本与容量；不以框架 API 作为知识主线。

## 组件映射

Structured Output、Vector Search、RAG、Tool Calling、Workflow、State Machine、Agent Loop、Evaluation、Guardrails、Replay 与 Observability 组件。

## 综合项目演进

增加内容理解、RAG、工具调用或 Agent 能力，并建立评估、安全、观测和成本控制。

## 阶段挑战

评审 Prompt Injection、权限、工具失败、无限循环与模型降级下的安全边界、恢复和成本。

## 阅读顺序

以可运行的推荐服务及其评估闭环为进入条件；完成 AI 能力的安全与成本挑战后进入综合架构评审。
