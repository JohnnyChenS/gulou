# 登山

登山学习的核心不是完成三级课程，而是知道自己在什么条件下可以出发、什么时候必须改变计划，以及谁能在现场提供帮助。先按路线要求选择内容，不按年龄或“勇气”判断资格。

## 从哪里开始

| 你的情况 | 阅读 |
| --- | --- |
| 还不能独立说明路线、天气、联系人和撤退条件 | [登山入门](beginner.md) |
| 已完成简单路线，准备面对多日、高海拔或技术训练 | [登山进阶](intermediate.md) |
| 已有相似条件下的训练记录，准备复盘自主规划或带队 | [登山高阶](advanced.md) |

完成过几次徒步不自动获得技术资格。绳索、冰雪、攀岩、高海拔和救援能力必须在合格教练或向导的现场训练中验证。

## 每次活动都要回答

- 路线、天气、开放状态和队伍条件是否与计划匹配？
- 哪个变化会让我们取消、折返、下降或联系救援？
- 谁掌握官方信息、通讯、急救和撤退安排？
- 行程结束后，我们能否说清哪里做对了、哪里仍需训练？

网页内容只能帮助整理问题。当地管理方、专业教练、向导、医生和救援人员的现场判断优先；出现严重症状或无法保证安全时，先停止并求助。
