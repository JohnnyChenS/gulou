# 母语与多语言互动

> **一句话**：0–3 岁的语言经验首先来自有人注意到孩子、等他回应，再把他的声音、动作和兴趣接回来；不需要用词汇量或固定分钟数给语言发展打分。

## 语言从“来回”开始

婴幼儿的沟通不只有说词语。看向你、转头寻找声音、微笑、发声、挥手、指向、递物、拉你的手、模仿动作和理解熟悉的话，都可能是沟通的一部分。表达性语言通常是在这些早期来回经验上逐步长出来的，但不同孩子的顺序和速度可以不同。

研究和早期教育机构都强调回应性互动的价值。这里的重点不是让成人不停说话，而是让孩子有机会发起、成人有机会观察和回应，再留一点空间让孩子继续。互动质量不能简单换算成每天说了多少字，也不能用一个固定词数判断孩子是否正常。

## 按年龄阶段观察

| 大致阶段 | 可以留意的沟通变化 | 成人可以做什么 |
| --- | --- | --- |
| 0–6 个月 | 对人声、脸、节奏和熟悉照料者有不同反应；可能用哭声、表情或声音表达状态 | 抱近、看着孩子说话；模仿他的声音，停一下等他是否继续；根据疲劳和饥饿调整互动 |
| 6–12 个月 | 咿呀、模仿声音、看向被指的物品，可能用伸手、挥手、递物或指向沟通 | 跟随孩子正在看的东西命名；回应咿呀；用简单动作和词语一起示范 |
| 12–18 个月 | 可能理解熟悉的词和日常请求，使用手势、声音或少量有意义的词表达 | 接住孩子的手势和声音，用一个自然词或短句扩展；少问测试题，多描述当下 |
| 18–24 个月 | 词语和手势可能逐渐增多，开始把词语组合起来；理解和表达仍可能不同步 | 孩子说“车”时可以回应“红色的车来了”；留出轮流空间，接受不清楚但有意图的表达 |
| 24–36 个月 | 可能使用更长的短句、提问、讲述生活片段和参与假装游戏；清晰度和叙述能力差异很大 | 接着孩子的话再加一点信息；一起回顾当天发生的事；让孩子用熟悉语言讲、唱或编故事 |

这些阶段用于选择互动方式，不是逐项打勾的时间表。CDC 的里程碑清单是和专业人员沟通的工具，不是筛查或诊断工具；如果你担心，达到某一项也不必阻止你寻求帮助。

## 一个可重复的互动循环

### 1. 观察

先看孩子在关注什么、身体状态怎样。他是看着灯发声、把勺子递给你，还是已经转开、揉眼睛？从孩子正在做的事开始，比突然拿出一套教具更容易形成互动。

### 2. 等待

用一句短话或一个动作回应后，停一会儿。婴儿和幼儿需要时间处理声音、找到动作，再决定是否继续。等待不是要求孩子必须回答；他没有回应时，可以换时间或换活动。

### 3. 接回

孩子发出“啊”，你可以模仿“啊”；孩子指向球，你可以说“球，滚走了”；孩子把帽子递给你，你可以说“你要我戴帽子”。先回应他的意图，再补充语言，不急着纠正发音。

### 4. 扩展一点

在孩子现有表达上增加一个词或一个动作即可：“水”可以回应“要喝水”；“狗”可以回应“狗在跑”。如果孩子转开或烦躁，就停在当下的互动，不把扩展做成训练任务。

## 把语言放进日常生活

不需要专门安排一套复杂课程。可以在这些短场景里练习：

- **换衣或洗澡**：描述正在发生的动作和身体部位，等孩子用眼神、动作或声音回应；
- **吃饭**：说出食物、温度、软硬和孩子正在做的动作，不要求孩子跟读；
- **散步**：跟随孩子看向的车、树、鸟或人，先说一个词，再等待；
- **收拾和出门**：描述简单顺序，如“先放鞋，再关门”，同时配合动作；
- **共读和看图**：可以只看一页、重复一句、唱起来，孩子离开时结束；
- **家庭游戏**：把孩子感兴趣的动作和声音接到假装、搭建或躲猫猫里。

照料者说得不完美也没关系。稳定、自然、愿意回应的中文、方言或其他家庭语言，通常比成人为了“练习”而说得不自在更容易持续。

## 双语、多语和方言环境

同时接触两种或更多语言，不等于孩子会被语言“弄混”。孩子可能在同一句话中混用语言，也可能在不同人和情境中偏好不同语言；这本身不能说明语言发展有问题。评估时应把孩子所有语言中的理解、手势、声音、词语和交流意图一起看，而不是只数其中一种语言的词。

家长可以使用自己最自然、最能展开对话的语言，也可以唱歌、讲故事、共读和与亲友通话。没有必要为了追求某种输入比例而牺牲真实的互动。若担心发展，告诉专业人员孩子接触哪些语言、每天在哪些情境使用，以及每种语言里观察到的例子。

## 屏幕、故事机和录音能做什么

录音、故事机和屏幕可以在家庭中有一定用途，但它们不能替代成人与孩子之间的共同注意、轮流回应和根据孩子状态调整的对话。尤其不要把背景播放时间直接当作“语言输入量”。如果媒体让孩子少睡、少玩、少与人交流，就需要调整安排。

如果使用屏幕，可以尽量选择短暂、适龄、成人在场并能一起回应的内容；视频通话也更适合在成人陪伴下进行。具体年龄、时长和家庭安排应结合当地儿科指南与孩子的睡眠、进食和互动需要，不用把某个数字当作唯一标准。

## 常见误区

### 用词汇量给孩子排名

词语出现的时间、数量和增长方式都有差异。一个孩子可能先积累理解和手势，另一个孩子可能较早说词；单一数字不能替代对理解、听力、互动意图和变化趋势的观察。

### 把“多说”变成成人独白

一连串提问、快速命名和要求孩子重复，可能让互动变得像考试。可以少说一点，跟着孩子的关注说一句，然后等待他用任何方式接回。

### 把“说话晚”都归因于性格或双语

“贵人语迟”、男孩都晚说、双语一定导致延迟，都不能代替专业评估。如果孩子出现退步、听不清声音、很少使用沟通方式，或家长持续担心，应尽早咨询，而不是只等待。

### 让故事机或动画承担主要语言教学

孩子听到声音不等于与声音建立了共同意义。可以把设备内容当作共同活动的起点：成人在旁边指、说、暂停、回应；如果做不到，也不要把它当成真人互动的替代品。

## 什么时候需要咨询

以下线索不用于家庭诊断，但建议把具体记录带给儿科、儿童保健、听力专业人员或言语语言治疗师：

- 已经出现的声音、手势、词语、理解或社交沟通技能明显倒退；
- 在多种情境中对人声、环境声音或熟悉的互动邀请反应很少，需要排查听力和沟通问题；
- 到相应年龄阶段仍几乎没有有意图的目光、声音、手势或来回互动，且进展长期停滞；
- 不同语言合计的沟通能力持续让日常需要、游戏或关系互动难以进行。

专业人员会结合听力、理解、表达、手势、社交沟通、家庭语言和变化趋势进行判断。不要因为孩子会说几个词，或已经通过某一项里程碑，就取消你对其他方面的担心。

## 一个四周观察路径

如果你想系统地观察，可以只选一个场景，例如换衣、吃饭或共读：

1. **第一周**：记录孩子如何发起、如何回应，以及当时是否困、饿或忙于探索；
2. **第二周**：成人只练习“观察—等待—回应”，不增加额外任务；
3. **第三周**：在孩子已有表达上扩展一个词、动作或声音，并观察他是否愿意继续；
4. **第四周**：回看具体例子，决定继续当前做法、调整环境，还是把记录带给专业人员。

目标是更了解孩子的沟通方式，而不是让孩子在四周内达到一个固定词数。

## 今天就做一件事

在下一次换衣、吃饭或散步时，找到孩子正在关注的一件事，说一句短话，然后停下来等他的眼神、动作、声音或词语。只要有一次来回，就已经完成了今天的互动。
